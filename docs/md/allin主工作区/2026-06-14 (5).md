## 测试框架搭建 — D:\allin\not\test

为全哥的 allin 项目群创建了一个 tkinter Canvas 测试框架，支持 Console/GUI 双模式。

### 项目结构
```
D:\allin\not\test\
├── main.py              # 入口：--console / --gui / --demo / --passing
├── 运行测试.bat          # Windows 快捷启动菜单
├── test_cases.py        # 21 个示例测试用例（通过/失败/错误全覆盖）
├── core/
│   ├── error_types.py   # 错误类型枚举（ErrorCode 28种 + ErrorCategory + TestError）
│   ├── log_manager.py   # 多路日志管理器（控制台/GUI/file，彩色ANSI输出，线程安全）
│   └── test_runner.py   # 测试执行引擎（线程超时控制，异常自动归类）
├── gui/
│   ├── config.py        # 颜色/字体/尺寸集中配置（参考 OK 项目群风格）
│   └── canvas_view.py   # tkinter Canvas 可视化界面（自定义样式按钮、统计面板、结果卡片）
├── console/
│   └── console_ui.py    # 控制台界面
└── logs/                # 日志输出目录（自动创建时间戳文件）
```

### 关键设计决策
- **架构**: 引擎和UI分离 — core 独立于 tkinter，可在无GUI环境运行
- **Canvas GUI**: 全部使用 Canvas 绘制（渐变header、圆角按钮、彩色进度条、可滚动结果列表、实时日志面板），参考 D:\allin\not\OK 项目群的 MVVM 风格
- **错误分类**: 5 大类 28 种错误码（PASS/FAIL/ERROR/SKIP + 细类），异常自动映射到 ErrorCode
- **定位到的 bug**: threading.Lock() 不可重入导致 `log.error()` → `log()` 死锁，已改用 RLock 并重构了嵌套调用

### 错误码分类系统
- PASS-000: 测试通过
- FAIL-001~006: 断言失败（相等/真值/包含/异常/意外结果）
- ERR-001~012: 运行时错误（属性/类型/值/键/索引/除零/名称/系统/IO/递归/内存）
- ERR-101~104: 语法导入错误
- ERR-201: 超时错误
- ERR-301~303: 框架错误（setUp/tearDown/夹具）
- SKIP-000~002: 跳过（条件/平台）
- ERR-999: 未知错误

### 验证结果
- Console 模式: 21 个测试全部运行成功，耗时 0.02s，错误分类精准
- 日志文件: 主日志(test_run_*.log) + 错误详情(test_errors_*.log) 正常输出
- GUI 模式: 代码完成，Canvas 绘制逻辑已实现（无头环境无法实测渲染）

## 测试探针系统 — 冒烟测试

新增了测试探针（Probe）类别，用于冒烟测试。

### 新增文件
- `core/test_probe.py` — Probe 类 + ProbeManager（注册/筛选/批量执行）
- `probe_cases.py` — 21 个探针用例（7个P1关键 + 7个P2快速 + 7个P3常规含演示失败）

### 新增错误码
- PROBE-PASS: 探针通过
- PROBE-FAIL: 探针失败（检查条件不满足或异常）
- PROBE-SKIP: 探针跳过

### 探针设计
- **Probe**: 无副作用的只读检查点，返回 (passed: bool, detail: str)
- **ProbeManager**: 支持按 priority (1-5)、category、tags 筛选
- **Priority 分层**: P1=关键冒烟（必须全过）→ P2=快速验证 → P3=常规可选
- **工厂方法**: `ProbeManager.simple(name, condition, detail)` 快速创建条件探针

### 使用方式
```
python main.py --smoke              # 仅 P1 关键探针（冒烟）
python main.py --smoke --all        # 全部 21 个探针
python main.py --smoke --category 环境  # 按分类筛选
python main.py --smoke --priority 2 # 按优先级筛选
```

### 验证结果
- 冒烟探针: 7/7 通过 ✅
- 全量探针: 18/21 通过，3 个演示失败正确标记为 PROBE-FAIL
- 分类/优先级筛选均正常工作

## Ctrl+C 中断处理

为所有执行循环添加了 KeyboardInterrupt 优雅退出：

- **ProbeManager.run()** — 330 探针循环中 Ctrl+C 中断后保留已完成结果，打印部分汇总
- **TestRunner.run_tests()** — 21 测试循环中同理
- **main.py** — 注册 SIGINT 信号处理器，第一次 Ctrl+C 温柔提示，第二次强制退出
- **ConsoleUI.run()** — 已有外层 catch（作为安全网）

中断后的输出示例：
```
⚠️  用户中断 (Ctrl+C)
已执行 45/330 个探针，剩余 285 个未执行
中断前结果: 44/45 通过, 1 失败
```
