# 2026-06-17 工作日志

## 评估了 D:\allin\not\OK\draw 项目

### 项目简介
CA Render Engine — 连续细胞自动机可视化工具
- 5个核心模块：main.py / engine.py / renderer.py / composer.py / recipes.py + templates.py
- 66个JSON配方预设，60+数学公式模板（初始化21/演化22/颜色17）
- 功能：后处理特效、HUD、过渡动画、可视化配方编辑器、自动播放、截图

### 发现的主要 bug 和问题
1. **reload_current() 失效**：`switch_recipe(self.current_idx)` 被早返回逻辑 `if idx == self.current_idx: return` 拦截，R键重载实际无效
2. **_reset_grid() 性能瓶颈**：逐像素Python循环（256×192=49152次），切配方时卡顿
3. **侧边栏点击偏移1行**：clicked 计算没减去标题行高度（约22px）
4. **random绑定不一致**：logic路径传函数引用，numeric路径要传数组，行为不统一
5. **'反转灰阶'命名错误**：实际是 v/v/v 正常灰阶，不是1-v反转
6. **邻域核**：JSON有neighborhood.type字段但引擎只实现了Moore，未实现圆形核（Lenia需要）

### 综合评价
创意好、架构分层清晰、内容量扎实。距离OK差：reload bug + reset性能。用户未要求修复，仅评估。

## draw 项目 — 全屏支持

- F11 键切换全屏/窗口模式
- 全屏时自动按屏幕分辨率最大化 CA 渲染区域（侧边栏保持 180px）
- 进入全屏保存当前缩放倍数，退出全屏恢复
- ↑ ↓ 在全屏模式下缩放上限为屏幕可容纳的最大整数倍（不再受 max_scale=8 限制）
- 标题栏显示 `[F11 退出全屏]` 提示

- 修复 ↑ ↓ 缩放失效：将缩放键从参数面板消费分支拆分出来，← → Backspace 仍可被面板消费，↑ ↓ 始终走 zoom_in/zoom_out

- 全屏渲染重写：不再用整数倍 scale_level（留黑边），改用 smoothscale 保持宽高比撑满 CA 区域
- 窗口缩放重写：废弃 __init__ 里一次计算不再更新的 max_scale（含 min(8,...) 硬上限），改为 _get_max_window_scale() 动态计算
- _draw_cycle_bar 改用 _ca_draw_w/_ca_dx 自适应全屏/窗口两种模式
- 全屏下 zoom_in/zoom_out 提示"已最大化"
