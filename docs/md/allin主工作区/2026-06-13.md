# 2026-06-13 工作日志

## bee 项目 — 标签系统引入

**背景**: "前缀+怪物名"内容无法正确加载，KILL 任务匹配崩溃，词缀系统是死代码。

**实施的改动**:

1. **标签自动生成** (`data_service.py`)
   - `get_enemy_templates()` 加载时自动为每个模板注入 `tags` 字段
   - 标签 = {全名, race}，如"哥布林战士"→ tags: ["哥布林战士", "哥布林"]
   - 145 个敌人都生成了标签

2. **标签匹配替代 endswith** (`quest.py`, `quest_service.py`)
   - KILL 任务匹配从 `endswith` 改为 `self.target in enemy_tags`
   - 修复了 `"史莱姆 Lv.5".endswith("史莱姆")` → False 的 bug
   - 支持前缀变体：带前缀的哥布林战士仍匹配"哥布林"任务

3. **词缀池加载修复** (`game_init.py`, `json_pool.py`)
   - `_load_affix_pool()` 在 init/restart 时注入了 91 个词缀
   - 修复 `json_pool.py` 中前缀字段名 `"prefix"` 不匹配导致只加载 7 个回退词缀

4. **敌人数据增强** (`difficulty_service.py`, `combat_service.py`)
   - 敌人字典增加 `base_name`（基础名不含前缀等级）和 `tags` 字段
   - `on_kill` 接口改为接收完整 enemy dict 而非 name 字符串

**测试验证**: `test_tag_system.py` 4 项测试全部通过（标签生成、标签匹配、词缀加载、模板传递）

**修改文件清单**:
- `src/app/services/data_service.py` — 标签自动生成
- `src/app/services/difficulty_service.py` — 传递 tags/base_name
- `src/app/services/combat_service.py` — 敌人字典增加 tags/base_name
- `src/app/models/quest.py` — 标签匹配替代 endswith
- `src/app/services/quest_service.py` — 传递 enemy_tags
- `src/app/controllers/game_combat.py` — on_kill 传 enemy dict
- `src/app/controllers/game_init.py` — _load_affix_pool()
- `src/json_pool.py` — 修复前缀字段名 (prefix)

## bee 项目 — P0~P3 内容机制扩展（第二轮）

按优先级依次实现 7 项内容增强，全部通过测试验证。

### P0-1: 标签分类扩展 (data_service.py)
- 新增 `_RACE_CATEGORY` 映射：20 种族 → 7 生态分类（亡灵系/邪能系/龙系/元素系/机械系/自然系/人形系）
- 新增 `_RACE_SIZE` 映射：20 种族 → 3 体型（大型/中型/小型）
- 标签层级 L1→L4：全名 → 种族 → 分类+体型 → 阵营
- 如"哥布林战士" → tags: ["哥布林战士", "哥布林", "人形系", "中型", "混沌阵营"]

### P0-2: 敌人稀有度变体 (difficulty_service.py)
- `RARITY_TABLE`: 普通(80%/×1.0)、精英(15%/×1.5)、稀有(4%/×2.5)、传说(1%/×5.0)
- 不同稀有度有不同词缀数量和显示前缀标识（如"【精英】"）
- smoke_test 已验证精英变体 HP=433 vs 普通 HP=288

### P1-1: 词缀赋予属性 (difficulty_service.py)
- 91 词缀 → 全覆盖 AFFIX_EFFECTS 映射（火焰/冰霜/闪电/毒素/吸血/加速/防御/反伤/回复等 10+ 效果类型）
- `_parse_affix_effects()` 解析词缀关键词 → 战斗效果字典
- 效果上限保护（max 0.75 for百分比类, max 15 for数值类）
- 效果叠加: hp_up + damage_up + defense_up + 种族修正

### P1-2: 标签驱动掉落表 (item_service.py, game_combat.py)
- `TAG_MATERIALS`: 7 个生态分类 → 特定材料（如龙系→龙鳞/龙牙、亡灵系→灵魂精华/暗影碎片）
- `roll_materials()`: 根据敌人 tags + 稀有度摇材料
- 稀有度加成: 传说×5 掉落概率
- 材料直接转化为金币价值，日志展示材料名

### P2-1: 敌人种族技能 (difficulty_service.py)
- `RACIAL_ABILITIES`: 15 个种族 → 固化被动技能
- 亡灵/不死族 → death_rattle（死亡时造成伤害）
- 龙族 → 每 5 回合喷吐
- 构造体 → 反伤加成
- 吸血鬼 → 吸血加成
- 昆虫 → 结网减速
- 野兽/恶魔 → 低血量狂暴
- 史莱姆 → 概率分裂
- 虚空/暗影 → 额外闪避
- 天使/巨魔 → 每回合回血
- 巨人 → 概率眩晕

### P2-2: 阵营系统 (data_service.py + difficulty_service.py)
- `_RACE_FACTION` 映射：20 种族 → 4 阵营（混沌/自然/秩序/中立）
- 阵营标签自动注入敌人 tags，可与成就/神器联动

### P3: 房间环境标签 (dungeon_service.py, models/dungeon.py)
- `Room.environment` 字段：根据地牢前缀生成环境标签
- `PREFIX_ENVIRONMENT`: 16 个前缀 → 12 种环境（高温/严寒/雷暴/毒雾/死灵/暗影/诅咒/混沌/血域/破碎/荒芜/遗忘）
- `ENVIRONMENT_EFFECTS`: 环境 → 战斗修正（火焰+20%/冰霜-20%等）
- 地牢生成时环境标签自动附加到每个房间
