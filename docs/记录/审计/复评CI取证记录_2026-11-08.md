## 5. workflow 变红的两条根因（均来自 annotations）

1. **Windows 门禁 `gate_metrics.py --selfcheck` 崩溃**：
   `UnicodeEncodeError: 'charmap' codec can't encode characters in position 3-6` at `tools/gate/gate_metrics.py:598`（`print("== 治理度量 自测… ==")`）。Windows runner 的 `cp1252` 编码无法输出中文 —— 典型的跨机编码缺陷，与仓内「GBK 控制台 / UTF-8 BOM」纪律同源。
2. **Windows 门禁 `tools/deploy/test_restore_drill.ps1` 失败**：
   `restore-allin: 3 个文件 sha256 不一致，拒绝恢复（备份可能损坏）`，缺失 `08\platform-data\a.txt` / `b.txt` / `08\website-data\w.txt`；`[FAIL] restore-allin.ps1 失败（exit=1）`。恢复演练夹具在 Windows runner 上路径/文件清单不一致。
   另有 2 项 SKIP：`repo_hygiene(no-publish-area)`、`smoke:e2e(missing-node-deps)`。
3. **平台集成/接口测试 job** 仅 `Process completed with exit code 1`，无更细 annotation；细节需仓库 admin 权限的 job logs（本轮 403，未取得）。

**附带观察**：Linux 门禁 `status=incomplete fail=0 skips=3` 却 `conclusion=success` —— SKIP 已在汇总层单列（远端 `ded8bb8` 实现生效），但**退出码层仍把 incomplete 放行**，与「SKIP ≠ 通过」纪律仍有张力。
