# 2026-06-06 工作日志

## 修改 autowav.py（随机音乐生成器）

### 1. 相对路径改为绝对路径
- 新增 `SCRIPT_DIR = os.path.dirname(os.path.abspath(__file__))`
- `generate_music()` 输出路径默认保存在脚本目录
- `interactive_mode()` 默认输出路径使用绝对路径
- `batch_mode()` 批量生成使用绝对路径
- CLI `--random` 和 `--batch` 输出文件均使用绝对路径

### 2. 增加压缩算法
- **动态范围压缩（音频效果）**：新增 `dynamic_compression()` 函数
  - 支持阈值、压缩比、启动时间、释放时间参数
  - `generate_music()` 新增 `apply_compression` 参数
  - 交互模式可选是否开启动态压缩
  - 提升音频响度，让声音更饱满
- **GZIP 文件压缩**：新增 `save_gzip_wav()` 函数
  - CLI 支持 `--compress` 参数
  - 交互模式可选是否压缩
  - 测试：WAV 文件从 700 KB 压缩到 428 KB（减少 39%）

### 3. 增加音乐时长
- 默认小节数范围从 8-24 扩大到 8-48
- 交互模式小节数输入范围改为 4-64
- 新增 `generate_music_by_duration(target_duration)` 函数
- CLI 支持 `--duration N` 参数，按目标秒数自动计算小节数
- 支持生成约 10 秒到 3 分钟的音乐

### 4. 其他改进
- 重写主入口 `parse_args()`，支持更多参数
- 交互模式增加 GZIP 压缩选项
- 帮助信息更新，反映新功能
