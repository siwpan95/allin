# 2026-06-25 工作日志

## easy-ai 项目：重构为通用 AI 框架（零硬编码）

**问题**：原来的 `ai_core.py` 是一个硬编码了宫廷/陛下主题的 SimpleAICore，规则、安全词、兜底回复全部写死在代码里，只能用于特定叙事游戏。

**方案**：将 `D:\allin\tools\easy-ai` 重构为配置驱动、零硬编码、可嵌入任意项目的通用 AI 对话框架。

### 新文件结构
```
easy-ai/
├── __init__.py          # 包入口
├── core.py              # AICore 主类 + from_dict() / create() 便捷函数
├── config_loader.py     # ConfigLoader: JSON 配置加载与校验
├── memory.py            # MemoryStore: 学习/遗忘/查询/序列化
├── pipeline.py          # ResponsePipeline: 中间件链（安全→记忆→匹配→兜底）
├── matchers/
│   ├── __init__.py
│   ├── base.py          # BaseMatcher 抽象基类
│   ├── regex_matcher.py # RegexMatcher: 正则模式匹配 + 代词反射
│   └── fuzzy_matcher.py # FuzzyMatcher: TF-IDF语义 / 编辑距离降级
├── config.json          # 默认配置文件
├── main.py              # CLI 交互入口
├── ai_core.py           # 向后兼容包装器（SimpleAICore → AICore）
└── 初始方案.txt          # 保留原始设计文档
```

### 核心设计原则
1. **零硬编码**：所有规则、安全词、回复模板全部在 config.json 中定义
2. **可插拔匹配器**：RegexMatcher（正则）+ FuzzyMatcher（TF-IDF/编辑距离），按优先级链式调用
3. **管道架构**：空输入→安全过滤→记忆匹配→匹配器链→兜底，每阶段可独立启停
4. **无领域知识**：框架本身不含任何特定领域的内容（宫廷/游戏等）
5. **向后兼容**：保留 old API（SimpleAICore、restricted_topics、export_memory 等）

### 用法示例
```python
import sys; sys.path.insert(0, 'D:/allin/tools/easy-ai')
from core import AICore

# 零文件启动
ai = AICore()
ai.respond("你好")

# 配置文件驱动
ai = AICore("my_config.json")

# 动态配置
ai = from_dict({"rules": [...], "safety": {...}})

# 学习、存档
ai.learn("问题", "答案")
ai.save("state.json")
```

- CLI 交互入口正常

| 7 | 异步支持 | FastAPI + asyncio | `ai.respond_async()` 封装 `asyncio.to_thread` |
| 8 | 数学中文表达 | 自研 | 支持"四加五等于几""一百除以五"等中文口语数学 |


## 核心架构重构：AICore 是大脑，TRPG 是训练方法

全哥明确了项目真正的定位：不是"两个系统对接"，而是"以简易 AI 为核心，跑团是训练 AI 的一种方法"。

### 新增 ai_trainer.py
- `AITrainer` 类：将游戏事件自动转化为 AICore 的学习数据
- `on_scene_result()` — 场景检定 → AI 学习技能知识 + 叙事
- `on_combat_event()` — 战斗事件 → AI 学习敌人信息 + 战术
- `on_character_load()` — 角色加载 → AI 学习角色属性/技能/装备
- `on_rule_query()` — 规则知识 → AI 学习 GURPS 机制
- `TrainingRecord` 数据类 + JSON 导出

### 重构 integrate_paotuan.py
- AICore 从"辅助系统"升级为"核心大脑"
- 7 条种子知识预训练（游戏规则、骰子系统、专注点等）
- 场景/战斗事件自动触发 AI 学习
- 新增 /stats 和 /export 命令
- 结局时展示训练统计
- 关闭窗口时自动保存训练日志

### 训练流程
```
游戏事件 → AITrainer → ai.learn(question, answer) → AICore Memory
                ↓
         TrainingRecord → training_log.json
```

### 测试结果
