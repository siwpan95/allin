# CA 去重合并评估（alloy 纵深 · 2026-08-25）

> 对象：`alloy/media/primitives/ca_kernel.py`（pywallpaper/draw 谱系，numba JIT 5 核 + 配方公式路径） vs `alloy/media/ca/`（cellular_automaton 谱系，141 规则整数态引擎）。结论先行：**两者不合并**；真正该去的是 ca_kernel 与"配方公式"之间的重复与发散（方案 A）。

## 一、两侧盘点

| 维度 | ca_kernel + CAPrimitive（pywallpaper 谱系） | media/ca（cellular 谱系） |
|---|---|---|
| 数据模型 | float32 [0,1] 连续网格（公式初始化产生连续值） | uint8 整数态网格（num_states 2-30） |
| 演化语义 | **配方 JSON 里的 evolution.rule 公式**（asteval，唯一真相）；5 个 numba 核是名字关键词命中的"快路径" | 规则类（B/S 总述、Wireworld、Gray-Scott、Lenia 等 141 个） |
| 消费者 | CAPrimitive：音频调制视觉特效（PIL 渲染+后处理） | CellularAutomaton：桌面壁纸仿真应用 |
| 配方库 | 4972 个 JSON（初始化/演化/颜色三公式 + 超级公式参数） | 8 个 JSON 规则族（141 规则参数） |
| 依赖 | numpy + numba(0.67，**未声明在 requirements.txt**) + asteval + PIL | numpy |

## 二、实证数据（2026-08-25 实测）

1. **命中面**：4972 配方中 339 个（6.8%）名字命中 5 核关键词：PureDiffusion 173 / BZReaction 94 / GameOfLife 30 / Seeds 28 / HighLife 14；其余 93.2% 恒走公式路径。
2. **语义对比（核 vs 配方公式）**：
   - GameOfLife / HighLife / Seeds：核与公式**逐位一致**（GOL 二进制网格 20 步实测 20/20 相同）。
   - BZReaction：核=连续松弛模型（c>0.5 则 c+=dt(1-c)，否则向邻域均值扩散，dt=0.1）；配方公式=`1 if (c>0.5) else (0.5 if sum_n>1 else c)`（二元+半态规则）。**完全不同 → JIT 路径对 94 个 BZ 配方产生与公式路径不同的画面（潜在 bug，继承自 draw）。**
   - PureDiffusion：核扩散率 0.1；配方公式 `c + 0.20*(avg_n - c)` 速率 0.20。**速率不一致 → 173 个配方两种路径画面不同。**
3. **性能**：64×64 单步 JIT 0.044ms vs AST 0.350ms（8.0x）。但绝对值极小：即使 steps_per_frame=10、60fps 也仅 3.5ms/帧，壁纸渲染瓶颈在 PIL/后处理而非演化。
4. numba 0.67 在 Python 3.14 可用（JIT 真实生效），但 requirements.txt 未声明——无 numba 的环境静默降级到公式路径，进一步说明 JIT 只是可选优化。

## 三、合并判定

- **ca_kernel ↔ media/ca：不合并。** 数据模型（连续视觉 vs 整数态仿真）、消费者（特效原语 vs 壁纸应用）、配方语料（4972 公式配方 vs 141 参数规则）三线不同；强制合并需做 float/int 适配层，丢失连续语义（公式初始化的分数网格会被阈值化），零收益、高回归风险。分层共存是正确架构，保留现状（已在 alloy/media/README 记录）。
- **ca_kernel ↔ 配方公式：真重复只有 3 个生命类核；BZ/扩散 2 个核是"语义发散的错捷径"。**

## 四、推荐方案 A（去 JIT 快路径，公式为唯一真相）

1. CAPrimitive 恒走 AST 公式路径（配方 JSON 为唯一演化真相）；`use_jit` 配置兼容保留但不再改变行为。
2. `ca_kernel.py` 退役：可删除，或在文件头标注"遗留，仅史料"（建议先保留为只读史料一个月，观察 pywallpaper 侧无引用后删除）。
3. 收益：① 消掉未声明依赖 numba；② 消掉 268 行重复模块；③ 修复 BZ/扩散 267 个配方两种路径画面不一致的潜在 bug。
4. 代价：≤0.35ms/步（8x 减速但绝对值可忽略），无正确性损失（公式路径本就是 93% 配方的主路径）。
5. 验收：alloy 全量绿 + pywallpaper 8/8 双绿 + CAPrimitive 对 GameOfLife/BZReaction/Seeds 三配方渲染冒烟一致 + requirements/README 依赖描述清理。
