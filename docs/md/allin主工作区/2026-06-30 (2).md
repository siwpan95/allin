## 经验教训

- Python 文件移动后需检查 `sys.path` 注入逻辑（尤其是用 `__file__` 计算路径的）
- `os.path.dirname(os.path.abspath(__file__))` 的嵌套层数取决于文件在目录结构中的深度
- 整理项目时先用 Python `shutil.move` 批量移动，比 shell `mv` 更稳定（Windows Git Bash 权限问题）
