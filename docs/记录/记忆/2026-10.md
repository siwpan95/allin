## 条目

- **2026-10-28** [gitee] Gitee 每个仓有两个名字：`path`（英文 slug，克隆地址真正用的）
  与 `name`（显示名，可以是中文）。批量克隆时目录名一律取 `path`；拿 `name` 当目录名
  会造出中文目录并与既有英文目录重复（同一仓库两份落盘）。
- **2026-10-28** [windows] Windows 上删含 `.git` 的目录：`shutil.rmtree(ignore_errors=True)`
  遇只读文件会**静默失败**，留下半删目录，让后续 `git clone` 报
  「already exists and is not an empty directory」这类假失败。
  正确做法：先 `os.walk` 逐文件 `os.chmod` 清只读属性，再带 onerror 回调 rmtree。
- **2026-10-28** [gitee] 克隆中途报 `curl 56 schannel: server closed abruptly
  (missing close_notify)` 是 Gitee 侧瞬时断流，不是仓库坏：同命令重试即可过
  （实测第 2~3 次成功；单次超时给足 600s 以上，大仓 700s+ 也正常）。
- **2026-10-28** [windows] 仅大小写不同的目录改名（`Pomodmer` → `pomodmer`）会被
  大小写不敏感文件系统误判「已存在」：先改名到临时名，再从临时名改到目标名，两步 rename。
