# 2026-06-16

## 字体下载器 v2.0 重构

- 基于 webcopier 架构模式，重构 `D:/allin/tools/fonts/font_downloader2.py`
- **新增模块**：
  - `RateLimiter` — 线程安全速率控制（参考 webcopier）
  - `FontHTTPClient` — UA轮换池（9个身份）、自适应重试+指数退避、反爬状态码处理(403/429/503)、Session连接池复用
  - `FontCrawlEngine` — 三种爬取模式：浅层(当前页)/翻页/深层(列表→详情→下载)、sitemap发现、断点续传(.font_downloader_checkpoint.json)
  - `GoogleFontsEngine` — Google Fonts API 集成，支持搜索+下载
  - `FontSpiderGUI` — 三标签页UI（通用爬虫/Google Fonts/推荐站点）
- **并发下载**：ThreadPoolExecutor + 进度追踪
- **字体网站调研结果**（已写入代码内置站点列表）：
  - Google Fonts API ★ 最佳（1600+ OFL字体，REST API直链）
  - 猫啃网 maoken.com（817款免费商用中文）
  - 字体天下 fonts.net.cn（商用免费分区，直链）
  - 100font.com（免费商用字体大全，论坛架构）
  - Fontesk fontesk.com（13000+，部分商用）
  - 免费字体网 mianfeiziti.com
