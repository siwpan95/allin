# ADR-0007 —— 架构叙事正文迁入 docs/规范/SPEC-204，architecture/ 只留图与 ADR

- 状态：**accepted**（2026-11-04 落地：`docs/规范/SPEC-204-系统架构.md` 建立；`architecture/README.md`
  缩为指针页）
- 相关：ADR-0004（文档即测试判定口径）、`docs/规范/SPEC-005`（文档枢纽契约）、`docs/INDEX.md`

## Problem

`architecture/README.md` 刻意置于 `docs/` 之外以避开 D1/D8 登记税——结果是它作为
仓根 README 指向的「权威架构叙事」，却**不受任何门禁管辖**：

- 仓数数字漂移两代无人拦（124 → 135 → 138，README 与事实源早已对不上）；
- 2026-10-31/11-02 新增的 `website/` 与 `packages/` 两个子系统完全不在架构叙事里；
- 「工程视图不属于四分类」的豁免理由成立，但豁免范围被放大到了整个目录的正文。

## Decision

- 架构叙事正文迁入 `docs/规范/SPEC-204-系统架构.md`：进 INDEX 登记、受 D3 头部契约 /
  D9 章节锚点 / g19 文档即测试判据约束——「权威叙事必须可机检」；
- `architecture/` 只保留**二进制资产**（两张 SVG，本就该在文档契约之外）与
  `adr/`（现行决策留痕，与 `docs/记录/决策/` 的「现行 vs 冻结」分工不变），
  README 缩为指向上层规范的指针页；
- 数字口径纪律：SPEC-204 内的仓数/门禁数标注实测时点，并声明**现值唯一事实源 =
  `docs/事实源/机器分区索引.md`**（与 SPEC-105 同款写法）。

## Consequences

- 架构文档从此要过文档税（登记 + 契约校验）——这是豁免换来的漂移代价，值得；
- SVG 改动仍在判据外，纪律为「改 SVG 必同改 SPEC-204」（口头约定，在指针页声明）；
- 仓根 README 指向改为 SPEC-204 优先，`architecture/` 退居图源。
