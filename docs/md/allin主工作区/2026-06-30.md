## 参考 web 版和 web 修改版完善

参考 `D:\allin\pq6-4-4\src\pq-web` 和 `D:\allin\pq6-4-4\web-modified\ProgressQuest` 对 Python 版本进行了全面完善：

### 游戏机制修正
- **XP公式**：从线性 `20*level*60` 改为指数 `(20+1.15^level)*60`（与原始 Progress Quest 一致）
- **HP/MP公式**：`CON/3+1+rand(5)` → `CON/3+1+rand(4)`
- **剧情进度**：改为 `gain || !act` 条件（序幕阶段也能推进剧情）
- **任务进度**：保持 `gain && Plot.size()>1` 条件
- **初始武器**：`"Sharp Stick"` → `"Sharp Rock"`
- **序幕文本**：`"unexpected reserve"` → `"unrealized reserve"`

### 数据修正
- 怪物拼写：`Tyranosauraus Rex` → `Tyrannosaurus Rex`，`Doppleganger` → `Doppelganger`
- 法术拼写：`Innoculate` → `Inoculate`，`Tonsilectomy` → `Tonsillectomy`
- 序列化器添加旧存档兼容补丁（合并旧拼写）

### 新增功能
- **自动投骰**：角色创建时设定目标属性，自动循环Roll直到达标
- **中文本地化**：从 web-modified 的 translationDict.js 导入 300+ 条翻译（装备/法术/怪物/种族/职业/剧情）
- **三套主题**：经典、龙之皇冠（中世纪酒馆）、空洞骑士（暗色洞穴）
- **旅途日记**：显示游历开始时间、游历时长、总任务数、最佳装备/法术/属性
- **DNA编码**：按 D 键显示角色基因组（ATCG 64位序列）
- **暂停/继续**：按 P 键暂停或继续游戏
- **手动保存**：按 S 键手动保存
- **扩展罗马数字**：支持 4000+（使用上划线 notation）
- **库存复制机制**：库存 >250 时，有概率复制已有物品而非生成新物品
