## 第四轮：连连看(LINK)模式规则修正 + 提示补全

全哥反馈：连连看模式规则有问题，且提示只有上海麻将有、连连看没有。

### 根因
- LINK 模式复用了上海麻将的 **3D 分层乌龟布局**；`can_link` 把牌投影到 (row,col) 平面、忽略 layer
- 分层棋盘投影后所有层重叠、占用格几乎铺满 → `can_link` 几乎恒为 False
- 连锁后果：提示(`find_hint_pair` link 分支)永远找不到可消对（看起来"连连看没有提示"）、规则因层投影歧义而错乱

### 修复
- `services/layouts.py`：新增 `LayoutKind.LINK_FLAT` + `_link_flat_layout()` → 单层 12×12=144 平面网格
- `viewmodel/game_viewmodel.py`：`start_new_game` 对 LINK 模式强制用 LINK_FLAT（上海麻将仍用分层布局）
- `views/board_canvas.py`：
  - 新增可滚动容器（canvas + 垂直/水平滚动条），平面棋盘更大可滚动查看
  - `_pos_to_xy`/`_recompute_size` 按 `flat`(mode==LINK) 走平面坐标（格距 step=sz+th+sh+4，无层偏移）
- `views/hud.py`：LINK 模式 [L] 布局按钮禁用并提示；状态栏/帮助正确区分两种模式规则
- `main.py`：pack 滚动容器 `container` 而非 canvas

### 验证
- LINK 模式 board: 单层 (max_layer=0) 12×12=144
- `find_hint_pair(board,"link")` 能找到可连通对（`can_link=True`），Tk 下提示在棋盘画出 2 个高亮元素（之前永远为空）
- 选牌→消除→计分→撤销 + `has_solution(link)` 全通过
- 新增 `preview_link.png`（连连看平面模式截图，972×972）
- README 玩法/模式说明已更新为两种模式

  - `_show_hint` 连连看模式额外画出**连通路径线**（蓝线），让"提示"一目了然
