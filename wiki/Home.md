## 三句话说完它在干什么

1. **门禁**：14 道可执行检查，判的是凭据泄漏、写死的本机路径、`.gitignore` 是否覆盖密钥面、删文件是否留证、文本 I/O 是否声明编码、门禁被喂坏输入时是否会大声失败……每条都以退出码结束。
2. **文档枢纽**：`规范/`（约束）、`事实源/`（活台账，必须带观测时点）、`记录/`（证据流水，只增不改）四分类，外加一份唯一入口的索引。
3. **可移植**：`allin-governance init <目录>` 把上面两样东西装进任何仓库，跑完 `npm run check:governance` 就是绿的（实测：Linux 与 Windows 各一次）。

---

## 它不做什么

写在这里，比写在别处更该被看见：

- **不做代码风格**。这类东西交给 formatter，不要浪费判据。
- **不判"架构好不好"**。它只判能写成退出码的事；判断力没法机械化。
- **不承诺 API 稳定**。当前版本 `0.0.0a1`，占位系列，随时可能改。
- **还没被陌生人验证过**。跑通这套东西的人目前只有一个。CI 是机器，不是人。

## 一条命令（最短路径）

```bash
pip install allin-governance
allin-governance init my-repo
cd my-repo && npm run check:governance
```

预期结尾：

```
governance: 14/14 gate(s) clean
```

细节、前置条件与"跑不动时看哪里"，见 [一条命令上手](一条命令上手)。
