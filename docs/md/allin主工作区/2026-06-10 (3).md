## 模块化重构 + 风扇背景集成

### 模块化拆分（从1120行单文件拆为多模块）：
```

├── app.py              # 入口 (~160行), 含 FanSoundController
├── __init__.py          # 包导出
├── core/
│   ├── qiandao.py       # 签到逻辑 (QiandaoState, reinforcement_prob)
│   ├── face_engine.py   # 表情绘制引擎 (FaceEngine)
│   ├── fan_engine.py    # 风扇背景引擎 (FanEngine) - 自主运行
│   ├── expression_map.py # 签到结果→表情映射
│   └── audio.py         # 音频管理器 (8通道, 表情4+风扇4)
├── ui/
│   ├── common.py        # 公共UI工具 (圆角矩形, 进度条, 稀有度颜色)
│   ├── sign_panel.py    # 签到面板
│   ├── browse_panel.py  # 表情浏览面板
│   └── history_panel.py # 历史面板
├── fan_sounds/          # 11个恶搞风扇音效
└── sounds/              # 30个表情音效
```

### 风扇背景系统：
- 从 D:\allin\lap\project1 提取物理+渲染核心，简化为自主运行
- 3叶片旋转，自动随机变速 (120-600 RPM)
- 在屏幕左上角和右下角各绘制一个半透明风扇作为装饰
- 恶搞音效：idle=猫打呼噜, low=蜜蜂嗡嗡, medium=警笛, high=喷气放屁
- 风扇音效走独立 mixer 通道(4-7)，与表情音效(0-3)完全分离
- 音量分层：风扇音效整体低音量(0.08-0.17)，表情音效高音量(0.7)
