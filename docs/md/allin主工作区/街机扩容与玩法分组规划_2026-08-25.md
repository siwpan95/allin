## 二、平台库页玩法分组（S2-S3）

### 2.1 schema（S2）

- platform.yaml 新增可选字段 `gameplay:`（字符串数组，仅 game 类项目填写）；
- **受控枚举**（推荐）而非自由标签——平台注册表校验时 fail-loud，杜绝同玩法不同名：

```
KNOWN_GAMEPLAY = [arcade, survivor, driving, roulette, snake, idle, rpg, card, fishing, mahjong, building, moba, puzzle, sports, music, visual-novel, sim, chess, text]
```

- 校验：gameplay 非空时逐项必须在枚举内；非 game 类项目带 gameplay 报错（提示误标）。

### 2.3 库页分组 UI（S3）

- 库 Library 页顶部加**玩法筛选 chips**（从注册表动态收集 gameplay 值）：点 chip 过滤卡片流，默认"全部"；
- 卡片 meta 行显示玩法标签徽标；
- 分组形态二选一（拍板）：
  - A：筛选 chips（保持现有卡片流，最小改动）；
  - B：按玩法分节列表（每个玩法一节标题 + 卡片），无玩法项目归"其他"。
