# 2026-06-05 play 项目评估

## 项目: D:/allin/play — 放置拼好团 ASCII 版
- 放置挂机 RPG，Python + Tkinter + openpyxl
- 3,466 行代码，17 个模块
- 三层架构: Core(状态/数据) → Systems(逻辑) → UI(渲染)
- 综合评分 6.9/10

### 亮点
- 架构分层清晰，main.pyw 只做接线
- 数据驱动三级回退(Excel → JSON → 内置默认)设计优雅
- AutoPlayController 回调模式解耦引擎和 UI

### 关键问题
1. **Bug**: battle_screen.py `_auto_equip` 的 rarity 比较逻辑有误（Enum 值是 tuple 不是数字）
2. **错误处理弱**: data_loader 全用 `except Exception: pass` 吞错误
3. **GameState.load() 职责不全**: 需要外部 _init_game() 补充 roster 链接
4. **私有属性滥用**: state._item_dict 通过 type: ignore 注入

### 改进方向
- 修 rarity 比较bug
- 引入 logging 替代 print/pass
- GameState 统一恢复逻辑
- 战斗策略可配置化
