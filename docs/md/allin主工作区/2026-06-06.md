### 架构设计
```
pt/
  mirror_launcher.py    ← 启动入口（模组选择 + 游戏主循环）
  mirror_mvp.py         ← 游戏核心类（不再独立运行）

  modules/              ← 模组池目录

### ModuleManager 功能
- 扫描 modules/ 下所有子目录，加载各 module.json 的 meta 信息

### 核心理念（来自 upgrade_plan.html 第 4 章）
> 跑团的本质是一堆表格。Excel 是跑团的通用语言。Excel 模板 → char_importer.py / data_importer.py → JSON → 引擎消费

### 新增文件
- `make_templates.py` — 一键生成全部 14 个 Excel 模板（openpyxl，样式/公式/下拉验证）
- `char_importer.py` — Excel 角色卡导入器（5 Sheet→character.json，预算校验）
- `services/data_importer.py` — 增强：新增 9 个 Excel 导入方法
  - import_enemies_from_xlsx / import_items_from_xlsx
  - import_traps_from_xlsx / import_encounters_from_xlsx
  - import_loot_from_xlsx / import_reactions_from_xlsx
  - import_scenes_from_xlsx / import_scenes_from_xlsx_and_save
  - import_all_from_excel (批量)

### 14 个 Excel 模板（templates/）

| 分类 | 文件 | 用途 |
|------|------|------|
| 🎮 玩家侧 | character.xlsx | 空白角色卡（5 Sheet: 属性/技能/优劣势/特征/装备） |
| | 预置-调查记者.xlsx | 预置角色 ×4（含公式自动计算衍生值） |
| 🖥️ 主持人-数据 | enemy_builder.xlsx | 敌人/NPC（mook/elite/wildcard/boss + 特殊能力） |
| | item_builder.xlsx | 物品/装备（weapon/armor/tool/consumable/key_item） |
| | trap_builder.xlsx | 陷阱/机关（触发→察觉→伤害→解除） |
| | encounter_table.xlsx | 随机遭遇表（区域→掷骰→遭遇→难度） |
| | loot_table.xlsx | 战利品表（来源→掷骰→物品→数量→品质） |
| | npc_reaction.xlsx | NPC 反应表（GURPS 标准 7 级反应） |
| 📝 主持人-模组 | scene_builder.xlsx | 场景构建表（3 Act × Sheet，33 列 × 行=节点） |
| | module_meta.xlsx | 模组元信息（NPC/关键物品/结局/时间线） |
| 🗺️ 主持人-地图 | map_grid.xlsx | 网格地图（Excel 格子画地图：墙壁/节点/遭遇/安全区） |

### 导入管线验证
- char_importer.py → 4 预置角色完整导入：属性/技能/特征/优势/劣势/装备全匹配
- data_importer.py → 3 敌人/6 物品/2 陷阱/8 遭遇/6 战利品/7 NPC反应 → 全部导入
- scene_builder.xlsx → 3 Act / 7 节点（3 perception + 1 investigation + 1 feat + 2 combat + 1 explore）
- Excel→JSON 回对比验证：53/53 PASS

### 用户使用流程
1. 主持人：`python make_templates.py` → 生成全部模板
2. 玩家：在 character.xlsx 填表车卡
3. 主持人：`python char_importer.py templates/预置-调查记者.xlsx` → JSON
4. 主持人：`python -c "from services.data_importer import DataImporter; di = DataImporter(); di.import_all_from_excel()"` → JSON
5. 引擎：`python mirror_launcher.py` 消费 JSON

## v3.1 方案全阶段代码执行 + 运行时验证

### 新建文件（15 个模块 + 6 个数据文件）

**Model 层**:
- `character.py` — GURPS 角色 dataclass（四属性/衍生值/技能/特征/装备/快照/序列化）
- `enemy.py` — 敌人模型（mook/elite/wildcard/boss + 附庸阈值 + clone）
- `scene_engine.py` — 数据驱动场景引擎（module.json nodes[] → 按 scene_type 分发）
- `combat_engine.py` — 战斗引擎（倡议/攻击裁决/主动防御/休克/部位伤害）
- `environment_system.py` — 环境系统（标签管理/渐进恶化/玩家专注点动作）
- `item_system.py` — 物品运行时（装备/卸下/消耗品/效果查询）

**ViewModel 层**:
- `viewmodel.py` — 裁决包→叙事转换（锚点查表/伤害描述/衍生标签/特征触发/事件队列）

**协调器**:
- `scene_resolver.py` — 场景结算（专注点回复/印记消减/XP/执念检查）
- `xp_system.py` — XP/成长系统（属性购买价格 ST/HT=10, DX/IQ=20）
- `save_manager.py` — 存档管理（角色快照 + 游戏进度 JSON）
- `data_importer.py` — 统一导入器（角色/敌人/物品/场景→module.json）

**View 层**:
- `character_sheet.py` — 终端角色卡渲染（完整/紧凑两种模式）
- `terminal_renderer.py` — 终端渲染器（所有 print 收拢到单一模块）

**重构**:
- `mirror_mvp.py` — v2.0 核心引擎（MVVM 分离，集成所有子系统）
- `mirror_launcher.py` — v2.0 启动器（动态菜单/数据驱动/角色选择/战斗循环）

**数据文件**:
- `data/enemies.json` — 敌人库（巨鼠群/镜中倒影/镜中守卫）
- `data/items.json` — 物品库（手电筒/急救包/防弹背心/手枪/撬棍/铜镜）
- `characters/预置-调查记者.json` — IQ 13，调查 14
- `characters/预置-退役军警.json` — ST 13，近战 14
- `characters/预置-神秘学学者.json` — IQ 14，神秘学 16
- `characters/预置-街头混混.json` — DX 13，潜行/撬锁 14
