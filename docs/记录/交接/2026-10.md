## 四、教训（新坑，建议进 MEMORY）

1. **`.gitignore` 对已跟踪文件无效**：换基底后重建的忽略规则不会把已进索引的文件撤出，
   必须同时 `git rm --cached`。本轮因此差点把 `.dsh-home/.credentials.yaml` 提交进库（518 个文件）。
2. **"缓存也是输入"**：`lib/tsconfig.tsbuildinfo` 里记着已不存在的 `micromark-util-types@2.0.3` 路径，
   实体删净后 tsc 仍按缓存报错。删构建缓存是判据的一部分。
3. **批改必须显式排除安全包装**：给 `govlib.read_text` 注入它不接收的 `encoding=`，把门禁自己改崩。
4. **同一个数在不同"面"含义不同**：索引剔除 1,735 / 提交删除 1,207 / 新增 1,906。
   **报数必须带面名**（索引面 / 提交元数据面 / 工作树面）。
5. **porcelain 会把整目录折叠成一行** `?? governance/`：拿它做逐文件比对会得出"文件不在工作树"的假结论。
6. **长任务输出不得用管道截断**：`| Select-Object -First N` 提前关闭管道、留下 `index.lock`，
   会把"索引只写了一半"伪装成"提交成功"。
7. **`Set-Content` 无 `-Force` 静默失败**；`git cat-file | Set-Content` 会给写出的文件加 BOM。
   精确读写一律用 `[System.IO.File]::WriteAllBytes` 或 Python。
8. **真启动不能只建 host 面**：`build:lib:host` 过后 client 产物仍缺，启动报
   `packages/client/ui-settings-session-log/lib/client.js` ENOENT。必须跑完整 `pnpm run build`。

### 96.2 G: 的"快进"判断被推翻（自重事实）

### 103.6 ⚠ 本轮我自己造成并修掉的一处回归：改 `.ps1` 会**丢 UTF-8 BOM**
