## 视频生成团队 · 火车进站电影史版配复古钢琴BGM（2026-07-14 下午）
- 任务：给真实影像版全片(600s)叠复古钢琴BGM。灵映(子agent)两次都 429 限流失败(只跑11~35s即中断)，改主理人亲自用 ffmpeg 直跑。
- 素材：Erik Satie《Gymnopédie No.1》(1888/公有领域) FLAC，51.2s，Wikimedia Commons 经 cors.sh 代理下载(b/b7/Gymnopedie_No._1..ogg)。curl 写文件须用 Windows 路径(C:/...)而非 /c/...（本机curl是Windows原生版，不认/c/前缀，否则"系统找不到指定的文件"）。
- 本机 ffmpeg 三大滤镜坑（已逐一验证）：
  1. `afade=t=out` 把整段压成静音(-91dB)；`afade=t=in` 正常。需"结尾淡出"用 `apad=pad_dur=0.5` 补静音替代。
  2. `aloop` 滤镜失效：loop=N 只吐原长不循环，loop=-1 变静音。可靠循环用输入级 `-stream_loop N`（写在 -i 前）。
  3. `amix` 玄学bug：混合后 RMS 比单路旁白还低(-31dB，旁白被压)。改用 `[n][b]amerge=inputs=2[merged]` + `pan=stereo|c0=1.0*c0+0.8*c2|c1=1.0*c1+0.8*c3` 显式下混，增益可控(旁白1.0/BGM总增益≈0.24)。
- 无缝循环做法：素材先 `afade=t=in:d=0.5,apad=pad_dur=0.5` 造"淡入头+静音尾"，再 `-stream_loop 11` 铺满→atrim=0:600→lowpass=f=4500(复古)→volume=0.30→与旁白 pan 混音。
- 核验：ffprobe(1920x1080/600s/aac/0错) + volumedetect 对比(纯旁白-25.0dB → 配乐版-24.8dB，证明BGM进去了且没压旁白)。
- 产出：ling-cinema-v2/火车进站_电影史_真实影像版_配乐.mp4(52.9MB,1920x1080,600s)。
