# 端口分配表（唯一事实源，2026-08-24 起）

> 规则：新服务启动前**先查本表再选端口**；占用 = 改本表；禁止口头约定。
> 插件/应用的默认端口从本表读取（配置即数据）；插件独立更新时端口变更必须在此留痕。
> 分段约定：8xxx 用户面板/媒体服务；88xx-89xx 媒体子协议/本地代理；9xxx 内部控制 API。

## 预留段（未占用）

- 8020-8099：未来新面板/服务（按登记顺序分配）
- 8900-8999：本地代理/工具服务
- 9900-9996：内部控制 API

> **段划分的一处待统一（2026-09-24 登记 8787 时发现）**：`8787` 落在 **8000-8099 与 8800-8999 之间的空档**，
> 且偏离「88xx-89xx 媒体子协议/本地代理」的段约定。它是历史既成端口（聚合桥早已在跑），
> 故先如实登记、不改端口以免打断在跑的服务；**段的边界是否要覆盖 8700-8799 留待后续统一**。
