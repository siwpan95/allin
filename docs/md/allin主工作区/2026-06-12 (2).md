# 2026-06-12 工作记录

## Line Rider 阶段一重构

从单文件 `rider.py`（1525行）拆分为模块化架构：

### 新建文件
- `config.py` — 常量、材质、Rider 形状定义
- `camera.py` — Camera 类，平滑跟随 + 世界/屏幕坐标转换
- `track.py` — Track 类，贝塞尔导数求**真实法线**（修复了原代码 `get_normal_at()` 永远返回 `(0,-1)` 的 bug）
- `physics.py` — 力基摩擦模型 + CCD 子步碰撞检测（4 子步/帧）
- `rider_entity.py` — Rider sled 多边形渲染，根据切线角度旋转
- `audio.py` — AudioSynthesizer（保持原逻辑）
- `effects.py` — EchoRipple + Particle（世界坐标存储，相机转换渲染）
- `main.py` — App 主类，整合所有模块

### 核心改进
1. **法线计算**：`bezier_derivative()` → 切线 → 法线，不再硬编码
2. **Rider 渲染**：从圆圈改为 sled 多边形（滑板 + 身体 + 头部），跟随表面角度旋转
3. **相机跟随**：Camera 类 lerp 平滑跟拍，无限画布
4. **力基摩擦**：F = μN 替代直接改速度
5. **CCD**：4 子步/帧防高速穿透
6. **特效**：腾空波纹 + 粒子爆发（触地/起飞）
