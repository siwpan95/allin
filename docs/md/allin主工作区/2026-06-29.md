## PQ Multiverse 修复工作（晚间）

### 经验值条 bug 修复
- **根因**：`_kill_monster()` 只更新 `exp_bar.increment()` 但未同步 `character.exp`，`_update_bars()` 每 tick 用 `character.exp`(=0) 覆盖导致经验条永远归零
- **修复**：击杀怪物时同步 `character.exp += exp_gain`

### 剧情系统重构
- `PlotChapter` 新增字段：`unlocked`, `description`, `is_prologue`, `tasks_required`
- 原版机制还原：序章=纯文字背景介绍，章节按完成任务数逐步解锁（3→5→8→12→16→20→25→30）
- UI 改造：序章文字标签 + 动态复选框容器 + "还需N个任务解锁下章"提示

### themed_engine.py weight 参数清理
- 三处 `weight=item_data.weight` 替换为正确参数 `count=item_data.count`，`stat_bonus=dict(item_data.stat_bonus)`

- **架构理念**：游戏本体=骨架（运行逻辑），主题=血肉（文案数据），两者结合才是完整游戏
- `theme_base.py` 新增 `get_theme_description()` / `get_theme_info()` 方法
- `themed_engine.py` 的 `load_theme` 改为 `@classmethod`（开始界面可轻量加载主题，不创建引擎）
- 新建 `src/ui/start_screen.py`：主题选择列表 → 自动随机角色（名称可编辑，种族/职业纯随机）→ "重新随机"按钮 → "开始游戏"回调
- `PqMainWindow.__init__` 新增 `char_name/race/char_class` 参数
- `main.py` 重写：默认走开始界面流程；`--theme` 参数保留为跳过开始界面的快捷方式
- 原版PQ风格：Windows经典灰色控件，与主界面一致
