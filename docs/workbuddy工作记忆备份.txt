### 三、教训（本区间新增，已并入 G:\allin\docs MEMORY 调试铁律）

- Gitee 建 release 不带 `target_commitish` → 400；**附件上传漏 `/api/v5` → 404 HTML 静默失败**；`assets` 无 id，重传同名会并存 → 删整个 release 再重建。
- 「测试全绿」≠「这条路能跑」；漏 import 曾连踩三次 → 补 `test_imports.py` 逐模块 import 烟雾。
- 政策名单 fail-closed（宁可误拦）≠ 规则匹配必须严格——审计建议不采纳的正当情形（freeguard 相似域名）。
- 判断「是否分叉」先归一化换行符/BOM（`1,470c1,470` 全行不同 = 换行符差异特征）。
- 删 `.git/index` + 部分 `git add` + commit = 一次批量删除；重建索引用 `git reset --mixed`。
- 子进程 stdout 不能用 PIPE（>4KB 阻塞）→ 重定向文件；`$LASTEXITCODE` 会被管道覆盖；`.ps1` 正文绝不含中文。
- PowerShell 写 `refs` 带 CRLF 会坏 → 用 `git update-ref`。
- 生成的报告先问「能否重跑复现」，不能就默认不写盘。
