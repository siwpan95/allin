# `docs/记录/` —— 证据流水

> **准入判据**（详见 [`../规范/SPEC-005-文档枢纽契约.md`](../规范/SPEC-005-文档枢纽契约.md) §2）：
> 它是**某一次**发生的事的证据 / 流水 / 结论。回答「这是哪一天发生的事？」为「是」就放这里。
> **本类文档一律不作为约束** —— 即使它写着"必须执行"，那也是**当时那次**的执行要求。

## 本类硬性要求

1. **文件名带日期**：`<主题>_<YYYY-MM-DD>.md`；按月滚动的流水用 `<YYYY-MM>.md`（`docs_index.py` D4 强制）。
2. 正文首行写明：`> **本文是 <时点> 的一次性记录，不作为约束。**`
3. **只增不改**：事后发现记错，用**追加勘误节**，不重写正文（历史保全）。
4. 想长期化其中的要求 → **提炼进 `../规范/`**，本类只留证据并链接过去。
