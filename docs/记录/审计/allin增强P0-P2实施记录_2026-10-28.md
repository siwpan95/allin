## 五、踩坑留档（下次别再踩）

1. **新增门禁必须先 `git add` 再跑门禁**——门禁只扫 git 已跟踪文件，未入索引的新门禁会被 `g00-meta` 判 `untracked-support`。
2. **`git ls-files` 的输出不能按空白切分**——本仓有 `docs/md/**/2026-06-04 (3).md` 这类带空格的文件名；`govlib.tracked_files()` 已用 `-z`，自写的临时脚本要用同样的口径。
3. **正则的扩展名要「长优先 + 词尾边界」**——`js` 分支会把 `mcp-actions.jsonl` 截成 `.js`、`hooks.json` 截成 `hooks.js`，凭空造三条假红。
4. **读别人的清单拼路径，先对齐基准**——`registry.json` 的 `script` 相对 `tools/gate/`（与 `run.ts` 的 ROOT 一致），不是相对 `governance/`。
5. **npm 脚本解析要沿包链向上取并集**——`tools/gate/governance/package.json` 里没有 `scripts`，只在最近的包里找会把 `check:governance` 误判为不存在。
6. **提交信息用 `-F` 文件**——反引号与 `$(...)` 会被 shell 执行，中文长消息直接写 heredoc 会被吃掉半句。
