## 分卷规则（新增/续写前必读）

1. **按月分卷**：文件名固定 `<YYYY-MM>.md`；**同一节不跨卷**——某节开始于月末、结束于次月时，整节留在**开始**的那个月。
2. **节号连续**：节号在全系列内连续递增（§一、§二 … §七十六 …），**续编前先扫最新卷取最大号 + 1**（`SPEC-004 §调试铁律 45`：编号必须唯一且连续）。
   中文数字与阿拉伯数字混用时的现行形态：§一~§七十三 用中文序数，§74 起用「### NN.」阿拉伯序数。**保持既有形态，不重排历史节号。**
3. **每卷首行声明覆盖区间**（`docs_index.py` D7 校验），格式：`# 会话交接 · <YYYY-MM> 卷（<起> ~ <止>）`。
4. **只增不改**：已发布的卷不重写；勘误以追加节处理。
5. **引用方式**：引用某条事实时写「`记录/交接/2026-09.md` §六十八」——**带卷号与节号**，不要只写「交接里说」。
