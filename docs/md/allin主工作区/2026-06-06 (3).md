# 2026-06-06 工作日志

## BeeIdleRPG 难度系统修复

修复了蜂蜜挂机 RPG 的地狱开局问题。核心矛盾：DDA 动态难度系统的"保底"只保护了奖励（最低 30%），没保护玩家——敌人属性强化方向没有下限。

### 修改文件

**`src/app/services/difficulty_service.py`** — 4 处改动：
1. 新增 `MIN_ENHANCE = 0.35`：`_apply()` p=+1 方向现在有下限，敌人属性最低为基础值的 35%
2. DDA delta 范围扩展为非对称 `[-0.35, +0.15]`（原 ±0.15），负向范围更大以便有效降低难度
3. 新增 `DDA_STARTUP_DELTA = -0.15`：新角色启动保护，开局即享受降低难度
4. 慢杀响应加速：连败阈值 3→2，步长从半步升到全额

**`src/app/services/dungeon_service.py`** — 1 处改动：
1. `_spawn_enemies()` 新增队伍等级上限：敌人模板等级限制为 `avg_lv + 1`，防止 Lv1 玩家遇到 Lv3 兽人

### 效果对比

| 场景 | 修改前 | 修改后 |
|------|--------|--------|
| Lv1 哥布林 HP/ATK | 31 / 5.1 | 28 / 4.8 (含启动保护) |
| Lv1 可遇敌人 | 哥布林 + 兽人(HP62) | 仅哥布林 |
| DDA 最大减难 | 敌人 96% 基础值 | 敌人 35% 基础值 (有保底) |
| 慢杀响应 | 需 3 连败，每次 ±0.01 | 需 2 连败，每次 ±0.02 |
