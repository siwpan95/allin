# `docs/事实源/` —— 活台账

> **准入判据**（详见 [`../规范/SPEC-005-文档枢纽契约.md`](../规范/SPEC-005-文档枢纽契约.md) §2）：
> 它是**当前状态**的单一权威台账，别的文档/代码会来**取值**。回答「别人会来查这个值吗？」为「是」才放这里。
> **不放**：某一次发生的事（→ `../记录/`）、必须照做的规矩（→ `../规范/`）。

## 本类硬性要求

1. **文件名不带日期**（日期写在头部时点字段里）。
2. **头部必须三项齐全**：`时点` + `观测工具/命令` + `失效条件`（`g07-doc-freshness` 强制）。
3. **同一条事实只写一份**：值写在这里，理由与事故写在 `../规范/SPEC-004-调试铁律.md` 对应条目里，两边用链接互指，**不复制正文**。
4. 值发生变化时**就地更新**，并在同格内以「（原 …）」保留旧值 —— 不要新建一份"新版"。
