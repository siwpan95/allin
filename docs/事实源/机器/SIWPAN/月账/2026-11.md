**这一轮最值钱的三条认识**：

1. **换根自检本来就是「公共核能否独立」的判据**（交接卷 §201.5 就做过：临时目录、cwd 不在仓内、
   不 clone 仓、只装 wheel）。我一开始把「allin 侧 99 处引用」当成阻断项，等于把
   **开发期调用**误判成**运行时耦合** —— 全哥一句「别告诉我你是整个搬过去验证的」
   把工作量从 8–12 h 压到 1–2 h。**判据已有的时候，先想想它能不能直接复用。**
2. **约定不机械化就会退化**。交接卷 §216 定了交接卷按机标注，但只写在 README 里没人执行；
   升成 D18 判据（三重限定：只认月卷 / 只判生效月之后 / 每卷只判最新节）后才真立住。
   同一模式已复用三次：D16 计划闭环、D17 事实源留痕、D18 交接按机标注。
3. **「仓里对」不等于「用户拿到的对」**。toolkit 0.5.0 内容改了但版本号没改（线上是旧内容）、
   governance 1.1.1 不含后来的 `--root` 改动 —— 判据必须以**线上产物**为准
   （解包 wheel 看内容，不是看仓）。

**踩的坑**（都已修，细节在交接卷）：
