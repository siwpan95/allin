## 二、确实变了的五件事

1. **CPU 更强**：`i5-12600KF`（12 代，10 核 / 16 线程 @ 3686 MHz）强于旧机 `Family 6 Model 158`（Skylake 世代 @ ~2592 MHz）。
2. **内存减半**：**15.9 GB**（旧机 32 GB）。实测可用仅 4.3 GB。→ 跑模型推理／大规模并行构建前先评估占用。
3. **盘位重排**：
   - `C:` = 内置 GALAX **465.8 GB NTFS**（旧机 C: 为 119 GB；旧机「C 盘快满」那条规则在本机**不成立**，实测剩 292.3 GB）；
   - `D:` = 外置 SanDisk **7,451.9 GB exFAT**（卷标 `save`）—— **个人数据盘，不是工作区**；
   - `F:` / `G:` = 两块 WD Game Drive **3,726.0 GB NTFS**（**可拔，勿拔**）。
4. **旧机的内置 `C:` 没有一起过来** → `C:\Users\13122\.workbuddy`、`C:\Users\13122\.dsh`、`.agent-presets` 都不在。
   旧机的会话／服务状态随之不存在（**不迁、重建**）。本机 DSH home 是 `C:\Users\psw\.dsh`、用户名 `psw`。
5. **`F:` / `G:` 是外置盘** —— 换机时记得**一起带走这两块盘**；它们才是工作区本体。

## 三、由硬件派生、会影响日常操作的三件事

1. **exFAT（仅 `D:`）不支持硬链接与目录联接**
   实测：`Hard links are not supported` / `Incorrect function`。
   后果：① 文件写入工具在 `D:` 上报 `EISDIR`（其落盘策略用硬链接）；② 目录联接类方案在 `D:` 上不可用。
   **`C: / F: / G:` 均为 NTFS，能力完整** → 工作区与仓留在 NTFS 卷上。

2. **盘内文件带旧机 SID → git 报 `dubious ownership`**
   已配 `safe.directory` 13 条覆盖：`G:/repos/*`、`G:/allin`、`G:/platform`、`G:/local/*`、`G:/tools`、`G:/archive/*`、`G:/notpython`、`G:/assets`、`G:/workbuddy`、`G:/CodeBuddy`、`F:/venvs/*`、`F:/Python314`、`C:/deepseek-harness-master`。
   **换机后需重新配置一次。**

3. **约 6 个仓的 `.pytest_cache` / `.pytest_tmp` 权限受限**（旧机 SID 残留），`git status` 会打
   `warning: could not open directory`。**不影响 git 判定**（107 仓实测全干净）；要清需改 ACL 或删除，**本次未动**。
