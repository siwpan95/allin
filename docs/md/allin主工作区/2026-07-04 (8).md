## allin_engine — 统一游戏引擎

从 D:\allin 下 100+ 个项目中提炼，创建了统一可复用引擎。

### 成果
- 位置: D:\allin\allin_engine\
- 规模: 49 个 Python 文件, ~15,200 行代码
- 依赖: Python 3.10+ (numpy/scipy 可选)
- 全部语法检查和导入测试通过
- example_quickstart.py 6 个示例全部运行成功

### 架构 (11层)
| 层 | 来源 | 核心内容 |
|-----|------|---------|
| core/ | carimara_py + pywallpaper | ECS + EventBus + Config + Paths |
| world/ | carimara_py + hell below | GameState, MapData, Room, Item, Character, MapGraph |
| systems/ | hell below + carimara_py | Inventory, Puzzle, Command, SaveLoad, ModLoader |
| systems/combat/ | hell below | Card/Enemy/CombatEngine 卡牌战斗 |
| render/ | pywallpaper + hell below | ConsoleRenderer, ColorSystem, FormulaEngine, Animation |
| audio/ | bloodmusic | SynthVoice, MusicPattern, AudioSystem |
| fx/ | tools/particle | ParticleSystem + 10种预设效果 |
| ai/ | easy-ai + ollama_generator | NarrativeEngine, DialogueEngine, ContentGenerator |
| test/ | py_test_runner | TestRunner, ProbeManager |
| utils/ | carimara + hell below | JSONLoader, Logger, TextFormatter, Font |

### 关键设计决策
1. ECS: Entity 用自增整数 id + 可选字符串 eid, world 支持全局数据共享
2. EventBus: 递归保护 + 安全遍历 + once() 一次性监听 + 26种EventTypes
3. GameEngine装配器: chain式 add_core().add_world().add_systems()
4. 可选依赖懒加载: numpy 缺失时核心引擎仍可正常导入
5. 所有模块独立可用, 无硬编码耦合
