# Blur 项目引擎化记录

## 2026-06-12 — 渲染引擎声明式重构

### 目标
将 blur 项目从 "效果=Python类" 改造为 "效果=JSON配置"，实现零代码添加新壁纸效果。

### 结果
创建了完整引擎模块 `engine/`，支持 9 种绘制原语、4 种颜色系统、多目标音频映射。

### 新文件结构
```
engine/
├── __init__.py          # 导出入口
├── core.py              # EngineEffect — 声明式效果容器
├── color_system.py      # 颜色生成器 (solid/hsv_flow/energy/rainbow)
├── audio_map.py         # 音频→视觉属性映射
├── utils.py             # 坐标/尺寸解析
├── effect_loader.py     # JSON 效果加载 + 兼容桥接
├── README.md            # 完整文档 + 原语参数字典
└── primitives/
    ├── __init__.py      # 基类 + 注册表
    ├── bars.py          # 频谱柱状图
    ├── spikes.py        # 径向尖峰
    ├── waveform.py      # 波形曲线
    ├── vortex.py        # 漩涡粒子
    ├── circle_map.py    # 圆形映射
    ├── particles.py     # 粒子系统 (drift/orbit/fall/rise/bounce)
    ├── grid.py          # 2D 网格
    ├── drawing.py       # 自由绘制命令
    └── text_rain.py     # 文字雨
```

### 引擎效果示例 (effects/132~145.json)
14 个纯 JSON 效果：条形图、尖峰、漩涡、频谱环、漂移粒子、轨道粒子、脉冲网格、矩阵雨、双波形、水平条形图、快速漩涡、组合效果、弹跳粒子、自由绘制

### 集成点
- `effect_manager.py` _make_effect() — 识别 (engine_config,) 单元素组
- `render_system.py` load_effects() — class="EngineEffect" 直接存储配置
- 原有 131 个 Python 效果类完全不受影响

### 添加新效果流程
1. 复制任意 132_*.json
2. 修改 id/name/layers
3. 放到 effects/ 目录
→ 启动程序即生效，零代码

### 项目偏好
- 效果全部引擎化，JSON 驱动（编号 001-101）
- 新效果：`python effects/generate.py --id xxx --name "XXX" --type bars`
- 原语扩展：在 engine/primitives/ 下添加新文件 + @register_primitive

## 2026-06-13 — 完全引擎化（一刀切）

### 目标
清理新旧混杂状态，将全部 101 个效果迁移为纯引擎 JSON，删除所有 Python 效果类。

### 做了什么
1. **添加 `script` 原语** — ScriptCompat 包装对象，旧 draw() 代码几乎直接可用
   - 兼容 VisualEffect 的 self.draw_rect/circle/line/polygon/rgb API
2. **批量迁移** — tools/migrate_to_engine.py 自动提取所有效果类代码
   - 7 个简单模式 → 引擎原语，94 个复杂模式 → script 原语
3. **剥离 render_system.py** — 2620 → 220 行（91% 缩减）
   - 只保留主题和加载器
4. **清理 effects/** — 删除 143 个旧格式 JSON，保留 101 个引擎 JSON
5. **更新 generate.py / auto_registry.py** 适配新架构

### 结果
- 效果：145 个（全部 EngineEffect）
- render_system.py: 2620 → 220 行
- 添加效果：`python effects/generate.py` → 启动，零代码
- 原语分布：bars 17, circle_map 16, spikes 14, vortex 14, particles 12, waveform 6, text_rain 4, grid 4, drawing 3
- script: 58 个（物理模拟/3D投影/递归/元胞自动机等真正复杂算法）
- 原语覆盖率：60%

### 教训
- 错误1: 迁移时遗漏 101-130 参数化变体（30个JSON文件）— 已从备份重建
- 错误2: 把132-145引擎示例也删了 — 已恢复
- 错误3: 偷懒把88个效果塞进 script 而不是用原语升级 — 已修正，三轮升级
