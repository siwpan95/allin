# 安全策略

## 支持的版本

只有最新的 **2.x** 版本接收安全更新。

| 版本 | 是否维护 |
| --- | --- |
| 2.x | ✅ |
| 1.x | ❌ |

## 报告漏洞

请**不要**通过公开 issue 报告安全漏洞。

- 邮件：siwpan@users.noreply.github.com
- 或在代码托管平台上使用私密漏洞报告功能

我们会在 **14 days** 内确认收到，评估后在回复中给出修复计划与预计时间。
漏洞披露遵循 responsible disclosure 原则：修复版本发布之后再公开细节。

## 本项目自身的攻击面

repocheck 是一个**只读**的离线扫描器，它的设计目标是「不成为风险来源」：

- 不联网，不发任何网络请求；
- 不执行被测项目的代码（import 检查用的是 `ast.parse` 静态解析）；
- 调用的 git 命令全部是只读操作，并设置 `GIT_TERMINAL_PROMPT=0` 避免等待凭据输入；
- 读取文件时有大小上限与二进制嗅探，不会把巨型文件整个读进内存。

如果你发现上述边界被突破（例如某个输入能让 scanner 执行代码或死循环），
请按上面的渠道报告。
