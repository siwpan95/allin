### midjourney 插件版核心逻辑重写
- **根本问题**: 原 fetch 拦截 `/api/explore` 方案已过时，当前 Midjourney 探索页使用 CSS `background-image: image-set()` 嵌入 CDN 缩略图 URL，不再通过 JSON API 返回图像数据
- **方案**: 参考 `Midjourney Image Catcher` (github.com/KennethJefferson) 的 DOM 方案
- **改动**:
  - 删除 fetch 猴补丁，改为 `MutationObserver`（childList + subtree + attributeFilter:["style"]）
  - 从元素 `style` 属性的 `image-set()` 中提取 CDN URL（正则: `/url\(["']?(https:\/\/cdn\.midjourney\.com\/[^"')]+)["']?\)/g`）
  - 从 CDN URL 解析 job_id 和 variant（格式: `{cdn}/{job_id}/0_{variant}_{size}_N.webp`）
  - 保留原有 UI 面板、下载按钮、URL 构建逻辑
  - 新增 `scanExisting()` 首屏扫描 + `scanElement()` 递归子元素扫描
- 验证: CDN URL 格式未经真机测试，加载扩展后在 `https://www.midjourney.com/explore?tab=top` 打开 console 看是否有卡片出现
