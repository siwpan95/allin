## 十四、冒烟假绿事故与修复（2026-08-27 续，重要教训）

- **事故**：第一批十包首轮冒烟只查了「进程存活 5s」——而 PyInstaller 启动异常弹的 Failed-to-execute-script 对话框恰恰会让进程保持存活，导致假绿。用户实测至少 2 包报错（实际 3 包受影响：yasuo、webcopier、print 发布包缺字典）。
- **真实冒烟协议（此后强制）**：①调试构建（console=True，-dbg 后缀）→ ②Start-Process 带 RedirectStandardOutput/Error 捕获 stderr → ③检查 Traceback 文本，而非仅 alive。
- **根因与修复**：
  1. yasuo：启动器以顶层脚本执行 gui_app，包内相对导入失败 → 启动器改为 `from yasuo.gui_app import CryptoGUI`、spec pathex 指向 G:/repos、hiddenimports 补包名。
  2. webcopier：pymongo 3.8 自带顶层 bson 影子模块，requests_cache 误用其 `encode` 属性崩溃 → spec 排除 pymongo+bson（preconf 有 ImportError 守卫，自动降级占位序列化器）；cv2 误排除已回补（ddddocr win32 硬依赖 opencv）。
  3. print：dictionary 字典树 + user_dict.json 未打包（datas 为空）→ 补 datas；进一步裁剪只打包 config.py 实际引用的 chinese-dictionary-main/{character,word,idiom} + CC-CEDICT（poetry/MakeMeAHanzi/xinhua 等 1GB 下载物不打包）。
  4. auto_clicker：settings.json 补打包。
- **重发**：4 仓旧 release 已删重建（yasuo 912150 / print 912154 / auto_clicker 912166 / webcopier 912183），附件已换修复版；webcopier 改四卷 zip（core/text/cv/ocr，单卷 <100MB）。
