# 2026-06-11 工作记录

## sfx 音效下载器改造

### 核心改动（dl_sounds.py）
1. **抓取层重试机制** — `_download_one` 现在每个下载槽最多重试 3 个不同数据源（MAX_SCRAPE_RETRIES=3），而非一次失败就跳过
2. **源统计追踪** — `_source_stats` 字典记录每个数据源的成功/失败数，`main()` 结束时会打印带进度条的统计报告

### 新增 4 个数据源（14 → 18）
- **Zapsplat** (zapsplat.com) — Playwright 分类页 → CDN 直链
- **WavSource** (wavsource.com) — 静态站，直接 .wav 链接
- **Sampleswap** (sampleswap.org) — 免费采样站，列表页 mp3 提取
- **99Sounds** (99sounds.org) — 音效包页面，直链提取

### 扩充现有数据源
- QuickSounds: ID 范围 29000-29300 → 28000-30000
- FindSounds: 关键词 30 → 90 个
- Pixabay: 搜索词 44 → 88 个
- Myinstants: 列表页 10 → 16 个

### GUI 适配（gui.py）
- 移除预选数据源的逻辑，由 `_download_one` 内部处理重试
- 18 个数据源在 3 列网格中自动排列

### 第二轮改造 — 统一 Playwright + 源内部重试（15:28）

#### 问题
1. 5 个源仍用 urllib（Myinstants/AudioMicro/FindSounds/WavSource/Sampleswap），无 stealth.js 和 CF 绕行
2. 仅加重试次数（换源重试）不代表整体成功率增加 —— 每个源内部抓取逻辑本身没变强

#### 改动（dl_sounds.py）
- **全部 18 个源统一使用 Playwright** — 5 个 urllib 源改为 `_fetch_page`
- **所有源增加内部重试** — 源内尝试 2-5 个不同分类/页面/搜索词后再放弃，而非一次失败就返回 None
- **无限滚动站点加滚动加载** — Pixabay + Mixkit 用 `_fetch_page_scroll(scroll_count=3)` 触发懒加载，获取 3-5 倍更多内容

#### 改动（sfx_utils.py）
- 新增 `enhanced_fetch_page_scroll()` 函数：支持 scroll_count、scroll_delay、wait_selector、min_length 参数

#### 新版内部重试示例
```

Pixabay:     4 个搜索词 × 3 个详情页
Mixkit:      4 个分类 + scroll×3
FindSounds:  6 个关键词
AudioMicro:  4 个分类 × 3 个页码
```
