## draw/ CA 渲染引擎重构 + 公式模板生成器

### 完成内容
1. **main.py 重构**：删除硬编码 `create_demo_configs()`，新增 `load_effects_from_dir()` 从 `effects/` 自动扫描加载所有 JSON 配方。支持不限数量的配方热切换（Tab/←→/数字键）。补全 `tick`（fps/steps_per_frame）、`neighborhood.radius` 等字段解析。

2. **formula_templates.py 公式模板生成器**：
   - 三种交互模式：`--browse`（浏览）、`--batch`（批量生成10个预配）、交互式选择
   - 模板库含 10 初始化公式 + 10 演化规则 + 9 颜色映射 = 29 模板
   - 支持 `--generate <初始化> <演化> <颜色> [名称]` 命令行快速生成

3. **effects/ 新增 19 个配方**：4 原始 + 10 批量预配 + 5 手工定制
   - 突出配方：BZ反应化学振荡波、水面波纹2D波动方程、Voronoi晶界生长、FitzHugh-Nagumo神经激发、捕食者猎物空间模拟

### 修复的Bug
- **`^` 运算符**：astEval 中 `^`=XOR 而非乘方，所有公式 `^2`→`**2`
- **C 三元运算符**：`a ? b : c`→`b if a else c`（Python语法）
- **`random` 闭包污染**：`init_func(random=np.random.random())` 传返回值而非函数引用，导致第二次调用后 `random` 变 float → None

### 依赖
- Python 3.13.12（pygame 2.6.1 不支持 3.14）
- `run.bat` 指向 3.13.12 一键运行

### 架构
- main.py: `CARenderEngine` 核心引擎 + `FORMULA_TEMPLATES` 模板库 + `load_effects_from_dir()` 加载器
- formula_templates.py: 独立模板浏览器/生成器，import main 的模板库
- effects/*.json: 纯数据配方，热插拔
