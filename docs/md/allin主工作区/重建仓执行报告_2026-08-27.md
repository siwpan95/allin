## 六、踩坑记录（新会话照抄）

1. **含中文的 .ps1 直接写文件执行会整篇解析失败**（PowerShell 5.1 按 ANSI 读无 BOM UTF-8）；一律走 base64 → `[IO.File]::WriteAllBytes`（UTF-8 带 BOM）通道，脚本尽量 ASCII。
2. **gitee 建仓 API 的 `private=false` 不生效**（新仓全部建成私有）；转公开必须 PATCH 且**必须同时带 `name` 字段**（只传 private 报 400 `name is missing`）。
3. **gitee 改仓名 API**：PATCH 需同时传 `name`（显示名）与 `path`（URL slug），只传 name 只改显示名不改链接。
4. **分支删除 API 405**；用 `git push <url> :refs/heads/<branch>`（注意同名 tag 存在时 `--delete` 有歧义，必须完整 refspec）。
5. **匿名 API 限流**：高频调用后匿名请求全 403（约 1 小时窗口）；验证公开性可用 `git -c credential.helper= ls-remote`。
6. 令牌文件 `G:\私人令牌.txt` 为多行格式，取匹配 `^[0-9a-fA-F]{32}$` 的行。
7. **PowerShell 5.1 的 Get-Content 默认 ANSI 解码**：批量改含中文 UTF-8 文件会烤乱全部中文；改文件一律 `[IO.File]::ReadAllText($f,[Text.Encoding]::UTF8)` + `WriteAllText(UTF8)`。（本报告成稿后曾因此整批损坏，已恢复，教训永久保留。）
