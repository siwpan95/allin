## 二、引用消歧（**必读，曾出错**）

本工作区有**两套**编号，裸写会撞车：

| 写法 | 指向 | 例子 |
| --- | --- | --- |
| `铁律 N`（**0–5**） | `SPEC-001` 的命名铁律 | `铁律 5` = 路径不写死盘符 |
| `调试铁律 N`（**1–62**） | `SPEC-004` 的纪律编号 | `调试铁律 19` = 只 `git add <指定文件>` |
| `OPS-X*` | `SPEC-10x` 操作规范的清单项 | `OPS-E8` = 新建仓收尾四步 |

**裸写「铁律 4」在本工作区同时匹配两者 —— 引用一律带限定词。**
另：`调试铁律` 实际末号是 **62**；凡见到「1–58」的表述（治理 persona 段、DSH `RULES.md` 旧文）都是**过期值**，以 `SPEC-004` 为准。
