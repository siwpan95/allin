# 端口分配表（唯一事实源，2026-08-24 起）

> 规则：新服务启动前**先查本表再选端口**；占用 = 改本表；禁止口头约定。
> 插件/应用的默认端口从本表读取（配置即数据）；插件独立更新时端口变更必须在此留痕。
> 分段约定：8xxx 用户面板/媒体服务；88xx-89xx 媒体子协议/本地代理；9xxx 内部控制 API。
