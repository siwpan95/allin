# ADR-0010 —— 三面贯通与编排纪律工程化

> 状态：`accepted` ｜ 时点：2026-11-05 ｜ 决策人：全哥（Phase 0 四项拍板）+ 交付专家团（主理人汇编，产出与实施证据见工作区《项目交付方案》及 8 份专项交付物）

## Problem

SPEC-204 的「三面」（kernel CLI / platform 门户 / website 站点）各自有测试，但**没有跨面的端到端验证**——「贯通」只是叙事而非可执行事实；治理大脑（Agent 双形态）的 15 个专项 skill 路由只存在于两份人写文本里，**无机器可读台账、无对账门禁**，路由表腐化只能靠人眼；website 无开机自启与备份纪律，机器重启后服务断供、数据无每日镜像。

## Decision

1. **混合贯通（加边不加层）**：platform 为治理状态唯一聚合出口（portal 新增只读 `/api/overview` 与 `/api/orchestration`），website 为唯一整合 UI 面（服务端 BFF 代理，浏览器零新增暴露面），kernel 保持 CLI 定位（新增只读 `status` 子命令，纯文件读取）。写路径唯一：website admin+CSRF → 代理 → portal 既有启停端点。
2. **编排事实源机器可读**：新增 `tools/orchestration/routes.yaml`（15 条真实路由，受控 YAML 子集）+ **g21 门禁 `tools/gate/agent_parity.py`**（Python 标准库，三方对账 routes.yaml ⇄ SKILL.md 锚点 ⇄ GOVERNANCE 段锚点；锚点 `<!-- route:<id> -->` 计数=1；退出码 0/1/2/3）。产物 = `tools/gate/audit/g21-runs.jsonl` JSONL 逐行快照（行内自含 routes 数组，portal 免 YAML 解析；severity error|warn；判红三条件）。
3. **北极星验收**：`npm run smoke:e2e`（6 检查点：CLI 前门 → kernel 探测 → portal 回环探活 → website 探活 → g21 判据 → verify-mount；证据落 `e2e-runs.jsonl`）。
4. **部署守护面**：Task Scheduler 登录自启 + 失败重启（4 个 ALLIN-* 任务）；每日备份 robocopy /MIR 至仓外异盘（checkpoint(TRUNCATE) + manifest sha256 + 7 天轮转；密钥绝不入镜像，唯一通道 backup-key）。脚本入仓 `tools/deploy/`，注册动作由人执行。

## Alternatives considered

- **portal 扩容为统一反代网关** —— 否决：违背 portal「按需启动、PORT=0」已拍板形态；kernel 非 HTTP 服务，反代需先给它加 HTTP 面（违 ADR-0001 轻量定位）。
- **各面 HTTP 化 + 薄聚合层** —— 部分采纳（platform 已有 OpenAPI 契约做增量），kernel 侧否决：门禁留痕已是 JSONL 文件，HTTP 化是重复暴露。
- **纯文件监听总线** —— 否决：Windows 跨进程 watcher 语义不可靠；保留为事实源读侧（G3 文件级只读）。
- **g21 产物单快照 JSON** —— 否决（实施中改判）：Windows 覆写存在损坏窗口、崩溃行 `total=0` 有假绿漏洞；JSONL 追加写免锁、免费留明细历史（成员实证，主理人终裁 v3）。
- **routes.yaml 落 `preset/allin/`** —— 否决（初裁改判）：preset/ 单一职责是 DSH preset 载体；路由表消费方（g21/portal/status）全在执行器侧，事实跟消费者走 `tools/`（与 `tools/facts` 先例一致）。
- **生成式渲染双形态文本** —— 否决：机器渲染 Markdown 丢失治理段手写语义，漂移判据反而失灵；对账式（锚点）保留人写正文。
- **PM2 / NSSM 常驻** —— 否决/备选：PM2 Windows 后台异常有实测记录且年久失修；NSSM 需管理员，留作不登录常驻备选。

## Consequences

- 正面：贯通从叙事变 6 检查点可复跑事实（`smoke:e2e` 6/6 全绿）；路由表腐化被 g21 当 push 拦截（对冲「B) 红了 30 天」事故模式）；website 治理看板让平台状态/门禁健康/编排漂移有单一查看面；数据有每日异盘镜像。
- 代价：GOVERNANCE 段 +15 行路由清单（一次性同步成本，已过 g16/refresh/verify-mount 三关）；`run_all_gates.sh` +1 道门禁（实测全绿 4m18s，预算内）；website 新增治理代理信任面（admin+CSRF+审计三重收窄，platform 围栏代码零改动）。
- 边界：M4 密钥灾备演练是运维动作，涉及真实密钥，须全哥亲自执行（SPEC-106 §6 口径）；`repos/write-agent` 本机未克隆致 `platform npm run check` 红一项（既有环境缺口，非本变更引入；`PLATFORM_PATH_CHECK=absolute` 形状校验通过）。
