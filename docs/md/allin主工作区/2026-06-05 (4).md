## D:/allin/cal — MVC → MVVM 架构拆分

将原 `calculator.py`（888行单文件 MVC）拆分为 5 个文件：

| 文件 | 层 | 说明 |
|------|----|------|
| `utils.py` | 工具 | CryptoUtils 静态方法集合，无框架依赖 |
| `model.py` | Model | CalculatorModel，纯业务逻辑，import utils |
| `viewmodel.py` | ViewModel | CalculatorViewModel，持有 Observable 属性，作为 Model 观察者，暴露 on_button() 命令，通过 add_side_effect_handler 向外传递 quit/shuffle 信号 |
| `view.py` | View | CalculatorView，绑定 ViewModel Observable，按钮调用 vm.on_button()，shuffle() 由外部调用 |
| `main.py` | 入口 | 装配三层，注册副作用处理器，启动 mainloop |

- 原测试文件 `test_model.py` 已更新 import 路径为 `from model import CalculatorModel`
- 18 个测试全部通过
- MVVM 关键变化：消除 Controller；ViewModel 持 Observable 属性，View 单向绑定；副作用由 main.py 注册处理，ViewModel 只发信号不执行
