# `allin` preset —— 工作区治理模式的载体（可重装）

> **为什么这个目录存在**：本机工作区治理模式（"开卷必读四份事实源 + 三条铁律 + 本机边界"）
> 全部写在一段 persona 里。**那段 persona 原本只活在运行中的 DSH 部署内、未入任何 git，
> 而 DSH 0.1.7-rc.1 已把承载它的 `packages/preset/agent-presets/` 整包移除** —— 升级即失。
> 这里存的是**能原样重装**的副本，用来把"单点"变成"可复原"。

## 一、这份副本是什么（恒等式，可复核）

```
agent.cordis.yml  =  出厂 cordis preset 的组装（逐字节未改）
                  +  一段 6 空格缩进的治理段（27 行，插在 persona 的 prefix 块末尾）
```

**证明方式**（任何人可复跑）：

1. 从部署取 `packages/preset/agent-presets/presets/cordis/agent.cordis.yml`；
2. 删掉 `<!-- GOVERNANCE:BEGIN -->` 到 `<!-- GOVERNANCE:END -->`（含那 27 行）；
3. 结果应**逐行等于**出厂原件 —— 即本副本相对出厂件**只有治理段这一处改动**。

## 三、重装步骤（照抄即可）

目标路径：`%USERPROFILE%\.dsh\.agent-presets\allin\`（即 `$DSH_HOME/.agent-presets/allin/`）。

```powershell
$dst = "$env:USERPROFILE\.dsh\.agent-presets\allin"
New-Item -ItemType Directory -Path $dst -Force | Out-Null
Copy-Item 'G:\allin\preset\allin\agent.cordis.yml' $dst -Force
Copy-Item 'G:\allin\preset\allin\preset.yml'       $dst -Force

# 技能从部署内的出厂 cordis preset 复制（版本随上游走，不锁定）
$src = 'C:\deepseek-harness-master\packages\preset\agent-presets\presets\cordis\skills'
Copy-Item $src -Destination $dst -Recurse -Force

# 校验
(Get-FileHash "$dst\agent.cordis.yml" -Algorithm SHA256).Hash
# 期望 692225C6AC8ADB0912E97F6A3CC6209A51BABD972C973E51F31C354B1B47218B
```

### 装完必做两件事

1. **重启 DSH**，然后在 Web GUI 的 **设置 → Agent presets** 里确认出现「工作区治理」卡片；
2. 把它设为默认：`settings.yaml` 的 `agent-presets.default: allin`
   （当前部署此值为 `cordis`）。**改完只影响之后新建的会话**，本会话不变。

**回滚**：把 `agent-presets.default` 改回 `cordis`，或直接删掉 `allin\` 目录。两者互不影响。

## 四、为什么是这个做法（而不是往 `cordis.patch.yml` 写行）

`0.1.7-rc.1` 引入了声明式 preset（`@deepseek-ai/dsh-agent-preset` 行 + 注册表按 id 覆盖
`config.plugins`），**在那一版**把治理段写进 profile 补丁是更干净的出路。
但**本机运行的 `0.1.6-alpha.2` 没有这个语义**，其官方 README 原文：

> 「本层也没有表达『standard 加一处改动』的 patch 语义」

同一版 README 给出的路径就是**复制 preset 到可写根、改副本**，
部署内 `editing-cordis-compositions` 技能也明令「**永不编辑随包 preset**」。
故当前做法 = 复制副本。**升级到 0.1.7+ 后应改用补丁行**，那时本目录的组装文本仍可直接搬过去。

### 与"随包 preset"的优先级（易踩）

`agent-presets` 插件按 **shipped root → 配置 root → `$DSH_HOME/.agent-presets`** 顺序扫描，
**同名 id 由靠前的根赢**（`discovery.ts`：`first-root-wins per id`）。
所以本副本**不能**叫 `cordis` —— 叫了就永远被随包那份压住、永远不生效。id 取 `allin`。

## 五、已知边界（别指望它做什么）

| 项 | 事实 |
| --- | --- |
| **不保护部署本身** | 它保护的是"治理段可复原"，不是"部署不会坏"。checkout 那些未提交改动仍在风险里 |
| **副本会漂移** | 上游升级 `cordis` 后，本副本**不会**跟着更新（官方 README 明列为已知限制）。要跟上得重新复制再补治理段 |
| **技能编辑不即时** | 代际只以 `agent.cordis.yml` 为键；改旁边 skill 文件要等组装文件变动或进程重启才对新会话生效 |
| **治理段内容有滞后** | 段内只列了铁律 0/1/2，`G:\allin\docs\MEMORY.md` 已有**铁律 3**。以 `MEMORY.md` 为准 |
| **不是唯一副本** | 归档件在 [`../docs/治理persona段.md`](../../docs/治理persona段.md)（逐字节段 + 双 SHA256，含旧版校验方法） |
