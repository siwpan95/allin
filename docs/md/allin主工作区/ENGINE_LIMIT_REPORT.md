### 架构层面已知短板（与压测无关，属引擎设计边界）
- **无寻路求解器**〔已回灌引擎〕：MapGraph 仅无权邻接导航，MapData 仅字符网格读写，无加权最短路 / 网格 A*。 → `allin_engine/world/pathfinding.py` 的 `GraphPathFinder`(BFS/Dijkstra/A*) 与 `grid_astar`（4/8 连通）。
- **World 不可直接序列化**〔已回灌引擎〕：`World` 未继承 `Serializable`，需项目侧自行 to_dict。 → `allin_engine/core/world_serial.py` 的 `SerializableWorld(World)` 直接 `to_dict`/`from_dict`，可交给 `SaveLoadManager` 存档。
- **粒子为纯 Python 列表**〔已回灌引擎〕：fx 不依赖 numpy，10 万级受解释器开销制约。 → `allin_engine/fx/particle_np.py` 的 `NumpyParticleSystem` 向量化物理 + 力场，实测 ~13x 加速（见下）。
- **可选依赖运行时才报错**〔已回灌引擎〕：缺失依赖是调用期 ImportError。 → `allin_engine/core/deps.py` 提供 `feature_flags()` / `require()` / `MissingDependencyError`（带安装提示）。
- **音符解析器 B 音列缺陷（关键）**〔已根因修复·引擎〕：`synth.note_to_freq` 归一化 `.replace("B","b")` 使自然音 B 与降 B 查表失败。 → 已在 `allin_engine/audio/synth.py` 就地修复（按字母+升降号计数），`MENU`/`BATTLE`/`BOSS`/`VICTORY` 含 B 预设现可正常生成 WAV。
