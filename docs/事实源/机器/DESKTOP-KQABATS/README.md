# `DESKTOP-KQABATS` 机分区文件夹

本目录是 `DESKTOP-KQABATS` 机分区文件夹（一机一目录），**分区主文档见 [`DESKTOP-KQABATS.md`](DESKTOP-KQABATS.md)** ——
该机当前状态的权威取值以主文档为准，本页与其余内容都不是分区文件。

## 目录结构

| 路径 | 性质 | 说明 |
| --- | --- | --- |
| `DESKTOP-KQABATS.md` | 分区主文档 | 唯一随主机名同名的分区文件，g20 门禁 / `verify_facts.py` 的判定对象 |
| `附属/` | 随档保管区 | **本机暂未建**（无一次性产出的原始档案实物；空目录不入库） |
| `脚本/`、`截图/`、`快照/` | 预留 | **暂未建**；确有实物再建，空目录不入库 |

## `附属/` 准入判据

回答「**这条一次性产出的原始档案在哪**」为「是」才放这里：

- ✅ 放：随档保管的历史报告、硬件导出件、部署配方原件等**非现行事实**的原始件；
- ❌ 不放：当前状态值（只写主文档，同一条事实只写一份）；一次性事件的**叙述**
  （归 `docs/记录/`，本目录只收原始件不写叙事）；文件名**禁带日期**
  （事实源体系 D4 判据，日期信息写进文件内容）。

## 扩位判据（预留目录何时建）

- `脚本/`：出现该机专属、随档托管的可执行观测脚本时；
- `截图/`：确有随档截图时（每份图片同样需在 `docs/INDEX.md` 登记计数）；
- `快照/`：**不建** —— 与 `docs/记录/快照/` 职责重叠，历史快照一律留在记录区、
  本目录只放指针（冻结区纪律：引用而非移动）。
