### 112.6 补 D12：INDEX 交接表「覆盖区间」自述按**列语义**判（用户 2026-11-01「按下一步建议继续推进」）

（@`DESKTOP-KQABATS` 实测）

- **为什么补**：D9 刻意只认「紧邻型」与「本文件 §N」⇒ INDEX 登记表里那类**「覆盖区间」陈述**
  （`2026-08-27 ~ 08-30（§一~§五十八）`）**判不到** —— 而那正是历史上真出过错的形态

  ⇒ 按**列语义**判（不是字符间隔启发式）：交接表每行的**「覆盖区间」列**归该行链接的文件。
- **D12 三条判据**：(a) 列内每个 `§X` 都存在于该卷；(b) 声明的**末节 ≥ 该卷实际末节**（真实漏网形态）；
  (c) 声明的**日期区间 == 该卷卷首声明**。
  ⇒ 与 D10 串成闭合链：**正文日期 ≤ 卷首区间 == INDEX 登记**。
- ⚠ **关键认知：节号跨卷会重复** —— `§一` 在 2026-08 卷是「总体状态」、在 2026-10 卷是「用户拍板」
  （该卷在 `## 九十四` 之后又用 `## 一、`~`## 五、` 作子节）⇒ `§N` **必须带卷**才无歧义，
  全局判必然误报。D12 因此按卷判，且**不判「起节 ≤ 实际首节」**（首节取最小值不可靠）。

- ⚠⚠ **顺带查出一处「自检自欺欺人」**：补 D12 时复核自检夹具，发现**三个破坏用例都被同一个 D9 命中**

  否则新增的判据可能一直躺着没被跑过，而总数看着很美。
