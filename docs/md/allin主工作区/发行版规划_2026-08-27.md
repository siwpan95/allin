## 九、统一发行规范（74 个未发仓适用，2026-08-27 定稿）

1. **tag/版本**：`v<semver>`（首版 v1.0.0；应用内部版本如 webcopier 5.3 在发布正文注明，tag 独立计数）。
2. **CHANGELOG**：每仓维护 CHANGELOG.md（Keep a Changelog 风格：Added/Changed/Fixed 三段）；发布正文 = 对应版本段 + 特性摘要 + 安装说明。
3. **形态决策**（调研结论，见第十节）：
   - GUI 中型应用（有数据/资产/自启）→ onedir + Inno 安装包（样板 G:\repos\pywallpaper）。
   - GUI 小工具 / 小游戏 → **onefile 单 exe**（体积 <50MB 且启动可接受时；>50MB 或启动慢改用 onedir+zip）。
   - CLI / 库 / Node → 便携 zip（onedir 或纯源码 zip），README 注明依赖与用法。
4. **体积红线**（沿用）：drawpic/output 775MB、photovideo/output 1333MB、pdf/title、print/dictionary、midi 安装包、ling-train 视频资产——不打包；scipy 排除集照抄样板。
5. **杀软**：保持 upx=False；onefile 首启解压易误报，发布说明里附「误报说明与申诉指引」；有条件再上代码签名（EV）。
6. **发布动作**：gitee release（tag + 中文名 + changelog 正文 + exe 附件）；静默回环验证；README 加下载徽标与发布面链接。

## 十、调研依据（联网，2026-08-27）

- **onefile vs onedir**：onefile 每次启动解压到临时目录——首启更慢且更易被杀软标记；onedir 启动快、更适合 GUI 与中型应用（[PyInstaller Discussion #8970](https://github.com/orgs/pyinstaller/discussions/8970)、[Python 转 exe 综述](https://codegym.cc/groups/posts/python-script-to-exe)）。→ 样板 onedir contents_directory='.' 保持，小工具才用 onefile。
- **杀软误报**：PyInstaller 产物本身是误报重灾区；UPX 压缩进一步加剧（[codegym 综述](https://codegym.cc/groups/posts/python-script-to-exe)、[APM 误报案例](https://github.com/microsoft/apm/issues/487)）；缓解 = 不 UPX、代码签名、向厂商申诉。
- **版本与 changelog**：SemVer + Keep a Changelog 是社区标准（[Eclipse TRG 1.03 CHANGELOG.md](https://eclipse-tractusx.github.io/docs/release/trg-1/trg-1-03/)、[OSPO Release Guidelines](https://dsacms.github.io/ospo-guide/outbound/release-guidelines/)）。photo 仓已按 Keep a Changelog 维护，全仓对齐。
