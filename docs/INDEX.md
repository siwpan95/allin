## 新增文档怎么做（4 步，强制）

1. **定类别** —— 按 `SPEC-005` §2 判据表选 规范 / 事实源 / 记录；选不出 = 该拆。
2. **领编号或锚点** —— 规范领区间内最小空号；记录定日期或月份卷。
3. **写头部** —— 规范七项字段 / 事实源三项 / 记录一行声明。
4. **登记本文件** —— 加一行，然后跑 `python tools/gate/docs_index.py`。

> 门禁 D1 拦「文件在但没登记」，D2 拦「登记了但文件不在」——**本索引不可能悄悄过期**。
