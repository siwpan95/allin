### 已知注意事项
- 扁平包布局不适合 pip install -e，需手动设置 PYTHONPATH 或直接使用
- Arpeggiator.generate_arpeggio 是独立函数（非 dataclass 方法），调用方式：generate_arpeggio(arp, notes, bpm=120)
- SynthVoice 使用 freq 参数（非 note），需配合 note_to_freq() 转换
