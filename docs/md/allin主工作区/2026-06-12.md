## 诡秘之主序列途径模拟系统 v2.0 完善

基于博客园 Sakura-Lu 整理的22条途径完整设定，对 `D:\allin\project_root` 进行了大规模重构。

### 新增文件
- **pathways_data.py** — 22条途径从序列9到序列0的完整数据（名称、能力、扮演行为、仪式、诅咒、性别转换），约1400行
- **pathway_groups.py** — 9大权柄体系、途径互换规则、旧日等级、四大支柱

### 重构文件
- **sequences.py** — 从硬编码类继承改为数据驱动；新增 `Sequence` 类（工厂模式创建）；保留 `Thief`/`Fraudster` 向后兼容
- **ascension.py** — 新增仪式检查（序列5+）、途径切换、性别转换；新增 `ascend()`/`switch_pathway()` 便捷函数
- **anchor.py** — 新增信徒/传承/印象维度；分级锚强度需求；状态评估
- **pollution.py** — 新增污染来源追踪；`PollutionManager`；污染爆发异常
- **uniqueness.py** — 新增全局注册表；序列1非凡特性管理；持有者历史
- **role_playing.py** — 新增行为权重随机、仪式校验、单途径/途径切换演示函数
- **main.py** — 6个演示模式：basic/multi/switch/full/gender/world，命令行切换

### 运行方式
```
python main.py              # 默认运行完整旅程
python main.py world        # 世界观全览
python main.py basic        # 基础演示（向后兼容）
python main.py switch       # 途径切换
python main.py gender       # 性别转换
python main.py multi        # 多途径
python main.py all          # 全部
```

### 关键设计决策
- 保持数据驱动 + 类继承双模式，向后兼容原有 API
- 途径互换遵循原著规则（诡秘之主组序列3+，其他组序列4+）
- 仪式默认警告但不阻断（方便演示），可通过 `ritual_check` 回调接入

## GUI 图形界面 v2.1 · Canvas Edition

新增基于 tkinter Canvas 的完整图形界面 `gui_app.py`（1003行）。

### 界面架构
- **左栏 (260px)**：22条途径列表面板，按权柄体系分组，可滚动点击选择
- **中栏 (自适应)**：角色卡片（途径+塔罗+序列等级+能力+扮演行为+仪式）、三连仪表盘（污染/锚/消化弧形进度条）
- **右栏 (340px)**：扮演行为按钮、晋升/途径切换面板、随机事件、实时事件日志
- **顶部工具栏**：视图切换（角色/途径全景/权柄体系）

### 三视图系统
- **角色视图**：主操作界面，执行扮演→晋升→切换完整流程
- **途径全景**：22条途径卡片网格，序列9→0点状图
- **权柄体系**：9大权柄卡片，四大支柱高亮

### 中文字体
- 从系统复制 Noto Sans SC 字体文件到项目目录（Regular + Bold）
- 自动检测系统字体，退化链：Noto Sans SC → Microsoft YaHei → SimHei

### 运行

python gui_app.py          # 直接运行
run_gui.bat                # Windows 双击启动
