## 四、教训（可复用的两条）

1. **新增/修改文件在 commit 之后必须再跑一次 g01**：未跟踪文件不在 g01 扫描面内，提交前验证会假绿。这条并入「提交后门禁复跑」的口径。
2. **g01 的「live path」豁免是机器相关的**：一个路径在本机恰好存在即被豁免，换机/CI 上同样的字面量就变成 dead path 直接 BLOCK。文档示例里**根本不该出现**机器路径，哪怕当前被豁免——去盘符（`repos/<仓名>`）是唯一安全写法；`:509` 的「description 说不写死、example 却写死」正是这类漂移的典型形态。
