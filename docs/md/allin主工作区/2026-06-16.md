# 2026-06-16 设计记录

## 项目：个人小说网站设计
- 设计稿名称：星海书阁
- 设计风格：学术古风 × 暖色羊皮纸
- 配色：#FFFBEB（羊皮纸底）/ #2D2520（深胡桃木）/ #D97706（暗金点缀）
- 字体：Cormorant Garamond（标题）+ Libre Baskerville（正文）+ Cinzel（标签）

## 页面结构
1. Header — 深色导航栏 + Logo + 菜单 + CTA按钮
2. Hero — 非对称分栏（左文案右视觉）+ 双CTA
3. 作品展示区 — 特色书籍卡 + 小卡网格（Bento布局）
4. 关于作者 — 左照片右信息 + 数据指标
5. 章节试读 — 深色背景 + 精选章节卡片（一大两小）
6. 写作进度 — 时间线日志
7. 读者互动 — 评论卡片 + 邮件订阅表单
8. Footer — 品牌 + 链接组 + 版权
