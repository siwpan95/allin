## 托管挂机化（Idle / Auto-Play）落地

用户澄清真实目标：用状态机驱动"放置挂机"——自动开局、探索、进战、攻击、拾取、回城，循环往复。

- 新增 `autoplay.py`：`AutoPlayer` 控制器，policy 字典把 `fsm.current_state` 映射到 `_at_<state>` 策略方法；用 tkinter `after()` 循环步进。策略：preload(等) / main_menu(读档或 start_game("挂机者")) / hub→explore / explore→随机 region+start_explore / dungeon→enter_battle / combat→combat_action("attack") / victory(等) / custom_combat→custom_combat_action("attack") / status·workshop→return_hub / settings→back_to_hub|back_to_menu / transient(等)。API：start/stop/toggle/running。
- `gui.py` 接入：`__init__` 加 `self.auto_play=False` + `self.auto_player = AutoPlayer(self)`；主城加"托管挂机/停止托管"按钮（橙色高亮）。`start_game(name=None)` 支持挂机自动开局（跳过 messagebox、用传入名）。
- 挂机免弹窗 & 自动结算：combat_defeat / custom_defeat 在 `auto_play` 时跳过 messagebox；combat_victory / custom_victory 在 `auto_play` 时走 `_auto_resolve_drop`（更优则装备否则丢弃→return_hub）与 `_auto_resolve_custom_drop`（→return_workshop），无掉落也自动返回。
- 防重入：combat_action / custom_combat_action 开头加守卫（敌人或玩家已倒下则直接 return），避免 after() 延迟回调与 idle 循环重复触发战斗结算。
- i18n：en/zh 各加 `btn_idle` / `btn_idle_stop`。
