## 遇到的问题和解决方案

### 问题 1：字段名不匹配
- **问题**：Excel 中的列名是中文（如"基础名称"），但代码期望的是英文键名（如"name"）
- **解决**：在 `excel_to_json.py` 和 `json_pool.py` 中添加字段名转换功能，将中文列名映射为英文键名

### 问题 2：Excel 字段太少
- **问题**：`敌人模板.xlsx` 只有 3 列（基础名称、种族、描述），但 `enemy_templates.json` 需要 9 个字段
- **解决**：在 `excel_to_json.py` 中添加默认值；在 `json_pool.py` 中实现"从 JSON 补充完整字段"的逻辑

### 问题 3：openpyxl 模块未安装
- **问题**：运行 Python 脚本时提示 `ModuleNotFoundError: No module named 'openpyxl'`
- **解决**：使用 managed Python 环境安装 openpyxl：`C:/Users/13122/.workbuddy/binaries/python/versions/3.13.12/python.exe -m pip install openpyxl`
