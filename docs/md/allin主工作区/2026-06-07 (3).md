### Phase 3：音画联动（音频驱动视频画面）
- VideoGenerator.analyze_audio()：FFT 频谱分析，提取每帧：
  - volume (RMS音量)、bass/mid/treble (频段能量)、onset (节拍)
- 新增效果模式：频谱可视化（柱状图 + 曲线 + 节拍闪烁）
- 所有 7 种效果模式均支持音频驱动：
  - 元胞自动机：音量→粒子大小，低音→颜色亮度，节拍→粒子密度
  - 渐变流动：音量→流动速度，高频→层数/粒子数，节拍→亮度闪烁
  - 几何图形：音量→图形大小，中音→旋转速度，节拍→颜色闪烁
  - 分形图案：音量→复杂度，高频→迭代次数，节拍→颜色翻转
  - 噪声纹理：音量→噪声强度，节拍→中心高光
  - 脉冲波纹：音量→波纹数量，节拍→波纹速度，低音→大小
  - 频谱可视化：实时显示FFT频谱柱状图，节拍闪烁
- UI 新增：驱动音频浏览按钮 + 驱动强度 Scale 滑块
- 测试：7/7 效果模式均生成成功
