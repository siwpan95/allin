## 五、S0 结论

1. **宿主确认**：alloy 为唯一综合引擎（唯一 ECS/事件总线/Context/WorldLog）。
2. **S1 前置事实**：pywallpaper 自有 ecs.py 的 API 面（Entity.add/get/has/remove_component）与 alloy.core.ecs 需做 API 对照后以 shim 收敛；pywallpaper 全量测试（test_engine.py 5/5 + test_three_things.py 3/3 + 4706 效果加载）作为回归基线。
3. **S2 范围**：只并入"能力层"（formula_engine/primitives/recipes），内容层（effects JSON）与应用层（systems/）留在 pywallpaper。
4. **S3 观察项**：cellular_automaton 的规则/主题 vs 4973 配方超集判定，留 S3 细比。
