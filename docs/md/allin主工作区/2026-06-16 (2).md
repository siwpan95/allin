#### 2. 核心模块（core/）
- **identity.py** - 统一浏览器身份管理，合并 webcopier + sfx 身份池
  - 指纹一致性校验（反 FingerprintJS/CreepJS/PixelScan）
  - 内置7个回退身份
- **client.py** - 统一 HTTP 客户端
  - requests / curl_cffi 双后端
  - 域名级 Session 池（Cookie 隔离）
  - 反爬状态码自适应退避
  - 请求间隔抖动（避免均匀模式）
- **rate_limiter.py** - 统一限速器
  - `RateLimiter` - 线程安全限速
  - `DomainRateLimiter` - 域名级独立限速（增强点）
- **anti_bot.py** - 统一反爬对抗
  - Playwright 浏览器管理（定期重启防内存泄漏）
  - Cloudflare 挑战检测
  - 人机模拟（随机滚动/鼠标/点击）
  - 资源路由拦截（提速 3-5x）
  - 指纹一致性（locale/timezone/screen 对齐）
- **downloader.py** - 统一下载器
  - 并发下载、断点续传、进度回调
- **robots.py** - robots.txt 处理

#### 3. 引擎层（engines/）
- **base.py** - 基础抽象类
- **font_crawler.py** - 字体爬虫引擎
  - 支持：fontsnet/zeoseven/deep/shallow/auto 五种模式
  - fonts.net.cn 专属：POST `/font-download.html` 获取 CDN 临时链接
- **sfx_crawler.py** - 音效爬虫引擎
  - 18个数据源，JSON 配置驱动
  - 通用爬取器 + 专用爬取器
- **web_crawler.py** - 网页爬虫引擎
  - 单页/批量/整站（BFS）
  - 断点续传、sitemap.xml

#### 4. GUI（gui.py）
- 三标签页：🔤 字体爬虫 / 🎵 音效爬虫 / 🌐 网页爬虫
- 每个标签页有独立配置
- 底部统一按钮：开始/停止/打开输出文件夹

#### 5. 反爬增强（来自2025研究文章）
- 会话保持：Cookie/localStorage 跨请求复用
- 人机模拟：随机滚动/点击/鼠标移动
- TLS 指纹：curl_cffi 支持（已有，统一接口）
- 指纹一致性检测：UA/时区/语言/屏幕分辨率互检
- 域名级限速：每个域名独立限速
- Cloudflare Turnstile 检测：自动检测并等待
- 资源拦截：屏蔽图片/媒体/字体提速
