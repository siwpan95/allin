### 6. helminth 项目缺陷修复

**项目位置**: `D:\allin\not\OK\helminth\`

通过完整源码审查 + 实际运行测试，发现并修复 11 个缺陷（跨 7 个文件）：

#### P0 严重缺陷（4个）
1. **SfxEngine Playwright 强依赖** — 所有 SFX 爬取器都用 `pw_fetch`（Playwright），无 Playwright 时音效爬虫完全不工作。修复：新增 `_fetch_html` 方法，优先 HTTP 客户端，挑战页/内容过短时回退 Playwright。
2. **FontEngine ZeoSeven 无效链接** — 生成 `github:repo` 格式链接，Downloader 无法下载。修复：新增 `_resolve_github_releases` 方法，通过 GitHub API 解析实际 Release URL。
3. **WebEngine batch 模式未实现** — 退化为单页爬取，返回 `[[content]]` 嵌套列表。修复：实现 `_batch_fetch` 方法，支持逗号分隔 URL 或文件输入。
4. **Downloader 线程不安全** — `ok`/`fail`/`downloaded_set` 在多线程下无锁访问。修复：添加 `_batch_lock` 保护。

#### P1 中等缺陷（3个）
5. WebEngine `_site_crawl` 不检测挑战页 → 添加 `is_challenge_page` 检测 + Playwright 回退
6. SfxEngine `discover()` 忽略 `save_dir` → 接受参数，CLI/GUI 可指定输出目录
7. `rate_limiter.py` 的 `import random` 在文件底部 → 移到顶部

#### P2 轻微缺陷（4个）
8. `anti_bot.py` `fetch_page` 中 `html` 变量可能未定义 → 初始化 `html = ""`
9. GUI `_run_sfx` 不传输出目录 → 传递 `save_dir`
10. CLI `cmd_sfx` 不传 `--sources` 参数 → 传递 `sources=args.sources`
11. CLI `cmd_web` 无 `--output` 参数 → 添加并传递 `output_dir`

### 7. helminth 第二轮修复（实际运行问题）

用户反馈：字体爬取可用但成功率不高，音效和网页爬取都有问题。

#### P0 致命缺陷（2个）
1. **SfxEngine `_fetch_html` 无限递归** — Playwright 回退调了 `self._fetch_html`（自己）而非 `pw_fetch`，导致栈溢出。修复：改为调用 `pw_fetch`。
2. **RobotsManager 无超时卡死** — `robot.read()` 用 `urllib.request` 无超时，目标网站无响应时永久阻塞（WebEngine 卡死 2 分 40 秒）。修复：改用 `requests.get(timeout=8)` + `RobotFileParser.parse()`。

#### P1 成功率问题（5个）
3. **SfxEngine `_fetch_html` min_length=2000 阈值过高** — 很多音效站列表页不到 2000 字符，触发递归崩溃。修复：降到 500。
4. **FontEngine fontsnet 重复链接** — 每个字体 ID 返回多个 CDN URL，max_fonts=5 实际只覆盖 3 个字体。修复：按字体名去重（`seen_names` 集合）。
5. **WebEngine `_site_crawl` 不检查状态码** — 404/500 页面也被保存。修复：添加 `resp.status_code != 200` 检查。
6. **SfxEngine 下载不验证文件大小** — 可能保存 HTML 错误页。修复：检查 `len(resp.content) < 1024` 且非 audio content-type。
7. **SfxEngine 各爬取器不传 referer** — 很多音效站下载需要正确 Referer。修复：所有爬取器返回四元组 `(url, label, ext, referer)`。

#### 数据源配置修复（6个）
8. **6 个数据源配置字段名不匹配** — `category_slugs`/`search_slugs`/`packs`/`keywords`/`sound_id_range`/`index_page` 等自定义字段名，通用爬取器不认识。修复：增强 `_scrape_generic` 支持所有字段名。
9. **myinstants 配置 URL 已失效** — `/en/most-popular/` 等返回 404。修复：更新为新 URL 格式。
10. **新增 5 个专用爬取器** — `_scrape_mixkit`（CDN 模板）、`_scrape_pixabay`（JSON-LD contentUrl）、`_scrape_myinstants`（详情页 MP3）、`_scrape_findsounds`（搜索 API）、`_scrape_quicksounds`（ID 遍历）。
11. **zapsplat/audiomicro categories 是字符串列表** — 通用爬取器调 `c.get()` 崩溃。修复：`isinstance` 判断处理字符串和字典两种格式。
