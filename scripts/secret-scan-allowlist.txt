# 内联豁免注解（gov-credentials / repo-hygiene 的 `...: allow`）白名单
# ==========================================================================
# 唯一事实源：scripts/scan-secrets.sh（CI 增量扫描）与
#              tools/gate/governance/gates/g03_credentials.py（全树门禁）
# 同时读取本文件，两侧口径不允许漂移。
#
# 为什么需要白名单（2026-11-07 安全加固 F-01）：
#   原实现「任何文件里带注解的那一行整行跳过扫描」。外部贡献者只要在夹带真实
#   密钥的那一行末尾追加一个 20 来字符的注释，就能同时绕过两道凭据防线 ——
#   注解本身是被扫描内容的一部分，等于把豁免权交给了被扫描者。
#   现在注解只在**本文件登记的仓库自有夹具文件**内生效；出现在其它任何文件
#   一律不再豁免，且 CI 增量扫描会直接判失败（fail closed）。
#
# 维护规则：
#   - 一行一个仓相对路径（POSIX 分隔符），`#` 开头为注释，空行忽略。
#   - 新增夹具文件必须同时在这里登记 —— 这是**受评审的仓库自有配置**，
#     不是提交内容里可以自行声明的东西。
#   - 删除条目时先确认该文件内确实不再有需要豁免的合成夹具。
#   - 路径含中文时按 UTF-8 原样书写（git diff / git grep 侧均已关 quotepath）。
