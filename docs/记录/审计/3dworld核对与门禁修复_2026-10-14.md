## 三、五个缺陷：根因、证据、处置

### 3.1 仓根残留目录把 `test_compat` 打红（唯一真失败，且此前被掩盖）

* **现象**：`tests/test_compat.py` 两条断言失败 —— `这些顶层包仍然存在（P2-4 没搬干净）：['core','logic','presentation']`、
  `core 不是同一个对象：<module 'core' (namespace)> vs <module 'world3d.core'>`。
* **根因**：P2-4（`c75880e`）把 7 个顶层包收进 `world3d.*` 后，仓根 `core/ logic/ presentation/`
  **三个空目录未删**，里面只剩 `__pycache__` 与搬迁前的 `.pyc`（`*.cpython-313.pyc`，9/29–10/6 留下）。
  Python 把仅有 `__pycache__` 的目录当**命名空间包**（PEP 420），于是 `import core` 真的成功 ⇒ 兼容层断言必红。
* **判据**：`git ls-files core logic presentation` 输出为空（未跟踪）；`git status -uall` 计数 0（都被 `build/` 等无关规则之外的原因隐藏：
  正是 `.gitignore` 只写 `__pycache__/` 不匹配子目录，才让它们既不被跟踪也不显眼）。
* **假设验证（移走-复跑-放回）**：临时移走三个目录 → `ALL_COMPAT_TESTS_PASSED` **6/6** → 原样放回。
* **处置**：经用户放行**直接删除**三个目录（删除前逐项核验：各只含 1 个条目 `__pycache__`、均未被跟踪）。

### 3.2 `.gitignore` 覆盖不到子目录 `__pycache__`（3.1 的成因）

* **判据**：`git check-ignore -v core logic presentation` → **exit 1**（未被忽略）；规则只有 `__pycache__/`（根锚定）。
* **处置**：规则改为 `**/__pycache__/`，并把这次的完整因果写进 `.gitignore` 注释（防下次有人改回去）。

### 3.3 聚合 runner 在 GBK 控制台崩，**会把真失败一起吞掉**

* **现象**：`python scripts/run_all_tests.py` 抛
  `UnicodeEncodeError: 'gbk' codec can't encode character '\u037c'` —— 进程带栈退出，**一条模块结论都不打印**。
* **根因**：`print(out)` 用父进程 stdout 编码（Windows 默认 `cp936/GBK`）；子进程输出含 GBK 编不出的字符。
  子进程本身已按 `encoding='utf-8'` 解码，所以问题只在**再输出**这一跳。
* **为什么这条最危险**：它把「有模块跑挂」表达成「runner 崩了」，**3.1 的真失败就是这样被埋掉的**。
* **处置**：父进程加 `_force_utf8_stdout()`（`stdout/stderr` 均 `reconfigure(encoding='utf-8', errors='replace')`）。
  选 `errors='replace'` 是有意的：宁可个别字符显示成 `?`，也不让整段结论消失。

### 3.4 测试模块自己在 GBK 控制台崩（比 3.3 更广的同一根因）

* **现象**：`python -m tests.test_brickward` → **65 项里 64 通过**，`test_fuse_travels_with_bomb_regression`
  因 `'gbk' codec can't encode character '\u2286'` 判红；`test_volumetrics`(12→11)、`test_dof`、`test_motionblur`
  同样红。**断言消息里含 `⊆ − ⇒ ∇` 等数学符号**是本仓既有风格。
* **影响面**：`.github/workflows/ci.yml` 的两个 job 都直接跑 `python scripts/run_all_tests.py`
  （第 64 / 131 行），**全文没有 `PYTHONUTF8` / `PYTHONIOENCODING`** ⇒ Windows job 上 CI 一直是红的，
  且红的原因与业务无关。本机此前只用「设 `PYTHONUTF8=1`」手动跑，掩盖了这一点。
* **处置**：在 `tests/__init__.py` 加同款 stdio 钉死。**选这个落点的理由**：所有模块都以
  `python -m tests.<module>` 启动，Python 必定先 import 本包 ⇒ 一处覆盖全部模块，**逐模块直跑也生效**。

### 3.5 `verify.py` 自检注入的**硬编码字面量已漂移** ⇒ 该条自检形同装饰品

* **现象**：`--selfcheck` 里 `readme-demo-count` 报 FAIL，理由是
  `沙箱里找不到要替换的文本：README.md :: '**37 个独立示例与工具**'`。
* **双重危害**：① FAIL 的**理由不对**（是"注入没做成"，不是"门禁没拦住"），人会误判门禁坏了；
  ② 更糟 —— **注入根本没插进去，它再也不抓真漂移了**。
* **审计**：把 15 条注入目标逐条与盘上比对（脚本 `_3dw_selfcheck_targets.py`）：**14/15 有效，仅此 1 条漂移**。
* **处置**：新增 `_subst_first(pattern, new)`，**从盘上按正则取真实文案**再替换（示例数怎么变都命中"真实的那一处"）；
  找不到目标时抛 `AssertionError`（自检记为 FAIL，理由准确）。

### 3.6 顺带修掉的一处计数漂移（同源教训复发）

`README.md` 目录树那句 `run_all_tests.py 14 个测试模块的聚合 runner` 实际是 **21** 个 ——
`readme-test-modules` 门禁只核对**测试命令表**，不看目录树散文里的数字。
**处置**：改 21，并**扩展该门禁**去核 `(\d+)\s*个测试模块` 与 `MODULES` 长度一致。
理由是 `verify.py` 开头自己写着的教训：「同一件事被手改过 5~6 次」——那就别再靠手。

## 七、复盘：与计划的偏差 / 教训

1. **偏差（计划外重大事实）**：原定"小任务，直接核对 + 汇报"，实测**发现一个被掩盖的真失败**
   ⇒ 按 `SPEC-002 §二.4`「遇计划外重大事实 → 回头补问」升级：先把五个缺陷摆清、给出 1–5 处置清单、
   **等用户放行**（用户回复「全部 1–5」）。执行中未再出现新的重大事实。
2. **教训 A（会杀人的门禁比没有门禁更糟）**：`run_all_tests.py` 在 GBK 下崩，把"有模块失败"表达成"runner 崩了"。
   **判据**：如果一条聚合入口的失败模式与"被测代码失败"无法区分，它就会长期掩盖真失败。
   ⇒ 聚合入口必须保证"**无论被测内容含什么字符，都要把结论打出来**"。
3. **教训 B（自检的注入源硬编码 = 自检会过期）**：所有"用注入破坏来证明门禁有效"的自检，
   **注入源必须从盘上取，不能写在自检里**。写在自检里，它要么假失败（这次），要么静默失效（更坏）。
   ⇒ 与 `调试铁律 53`（门禁的排除项最危险）同源：**自检自己也会腐，得让它腐不了**。
4. **教训 C（同一条教训会复发）**：`verify.py` 开头已经写着「示例数 / 测试数被手改过 5~6 次」，
   而 `README` 的 `14 个测试模块` 又漂了 —— **说明"加一条门禁"比"要求人记得改"有效**：
   这次不是把 14 改成 21 就完事，而是**把这条数字纳入门禁**。
5. **教训 D（`.gitignore` 的目录规则是根锚定的）**：`__pycache__/` 只覆盖仓根。
   目录搬迁后残留的空目录会因为 `__pycache__` 而"半隐形"，并且**真的会改变 Python 的 import 结果**。
   ⇒ 搬迁类重构的收尾清单里应有「**核对旧顶层目录是否已从工作树消失**」，而不只是"源码是否已迁走"。
6. **教训 E（修一类缺陷前先扫全部落点）**：第一轮把 GBK 崩溃判为"`run_all_tests` 的问题"，
   只修了它与 `tests/`；`verify.py` 自己有同样的病，等改完 6.1 复跑门禁才暴露。
   ⇒ **宣称修好某一类之前，先按判据把这类缺陷的全部落点列出来**（本轮补扫：15 个入口脚本里
   10 个含此类符号，其中 4 个已接入兜底、6 个登记待办）。
   与 `调试铁律 69` 同型：**结论的覆盖面必须 ≥ 它自称的覆盖面**。
7. **教训 F（工具判据是形态匹配，不是语义匹配）**：注释里把删掉的绝对路径当反例抄回来，门禁照样判红。
   ⇒ 写"为什么删掉某个盘符路径"时，**用描述代替字面量**。
