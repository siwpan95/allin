## 2. 探索维度（三类引导，必填）

### 2.1 Heuristics（启发式）
- 失败注入：在恢复过程中故意制造源介质不可用、目标库锁定、网络抖动。
- 边界值：极小备份集 / 极大备份集、空备份、损坏的备份头。
- 时间序列：恢复窗口与线上读路径高峰重叠时的表现。

### 2.2 Oracles（预言 / 判定准则）
- 恢复后数据一致性可校验（校验和 / 行数比对）。
- 恢复过程对线上读路径的影响在容忍阈值内（或明确隔离）。
- 失败恢复有可审计日志，且失败时回滚到已知良好状态。

### 2.3 Tours（漫游路径）
- 安全漫游：密钥通道独立性——恢复用的密钥与日常运维密钥是否隔离。
- 历史/回归漫游：对照既往 `restore-drill-task.ps1` 的执行记录，验证「可复跑」。
- 数据流漫游：从备份落盘 → 拉取 → 恢复 → 校验的完整链路。

## 4. 目标与退出条件

- **目标**：
  1. 验证恢复演练在故障注入下仍能给出确定性的 PASS/FAIL 判定。
  2. 验证密钥通道与敏感材质隔离假设成立。
- **退出条件**：
  - [x] 时间盒耗尽且关键路径已覆盖
  - [ ] 所有目标达成
  - [ ] 发现阻塞级缺陷

---

## 5. 风险假设

- 假设 1：恢复演练不应影响线上读路径（隔离假设）。
- 假设 2：恢复所用密钥通道独立于日常运维通道（密钥独立性假设）。
- 假设 3：敏感材质（如含 PII 的备份）在恢复演练中保持隔离，不落到非受控位置。
