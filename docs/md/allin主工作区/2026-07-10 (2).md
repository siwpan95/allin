# 2026-07-10

## remix 项目 — 加入视频音频合成功能

### 新增文件
- `core/video_processor.py` — VideoProcessor 类，基于 ffmpeg/ffprobe 实现：
  - `get_video_info()` — 用 ffprobe 获取视频元信息（时长/分辨率/编码/帧率/音频参数）
  - `extract_audio()` — 从视频提取音频轨道（支持 wav/mp3/aac/ogg）
  - `mux_audio_video()` — 音频合成到视频，支持两种模式：
    - REPLACE：完全替换视频原音频
    - MIX：原音频 + 新音频混合（背景音乐模式，可调音量）
  - `extract_and_load()` — 便捷封装
- `tests/test_video_processor.py` — 完整单元测试（24 项），含 ffmpeg 生成的测试视频

### 修改文件
- `gui/main_window.py` — 重构为双标签页 Notebook：
  - Tab "音频混音"：保留全部原有功能
  - Tab "视频合成"：视频选择→信息展示→音频提取→合成（替换/混入背景音）
- `core/__init__.py` — 导出 VideoProcessor / VideoInfo / MuxMode
- `requirements.txt` — 新增 audioop-lts>=0.2.2（Python 3.13+ pydub 兼容）
