# 平台立项报告：Steam 式全项目集成平台（2026-08-25）

> 用户方向：**把目前所有项目集成到一个平台，类似 Steam**。用户自述三块积累：尝试过创意工坊、已有综合引擎（alloy）、认为"平台是实现插件化最好的基本架构"。
> 本报告为立项交付：盘点既有积木 → 提出架构 → 列拍板问题。**未拍板前不动手。**

## 一、为什么这次能做（理论支持 = 既有三纪律，不是新发明）

过去失败根因（《全景梳理》§0）：代码级融合 → 失去独立更新 → 融合框架被冷落（helminth/media_engine/ECommerceCrawlers/M5 单进程）。
插件化改变的是**整合的定义**：整合 = 装配（声明依赖/注册能力/可逆副作用），不是合并代码。

Steam 的三层结构与本仓库的对应物**已经全部存在**：

| Steam | 本仓库既有积木 | 状态 |
|---|---|---|
| 客户端（库+启动+状态） | **portal（:9000）**：iframe 分页签 + 聚合状态卡 + 本机启停（M5 方案 B 落地，2026-08-24 上线） | ✅ 种子已存在 |
| 创意工坊（订阅/更新/回滚） | **插件注册表模式**：crawl_hub crawlers.json（聚合不融合+子进程隔离+--check 审计）+ alloy patch 纪律（补丁即差异）+ gitee 发布面（44 仓全公开） | ✅ 零件齐备，未组装成"工坊" |
| 引擎（游戏运行时） | **alloy**：Context 可逆装配 + preset/profile + WorldLog + sync/dump CLI + media 子系统（J2 完成） | ✅ 已收敛为唯一综合引擎 |
| 网络层（服务发现） | **端口分配表**（唯一事实源）+ 9 个已用端口 | ✅ 有表，尚未机器可读 |
| 账户/商店 | gitee（开源优先，44 公开仓） | ✅ 分发层用 gitee 即可，不造商店 |

→ 平台 = **把四块积木装配起来**：portal 升级为"库+工坊"前台，注册表/端口表机器可读，插件生命周期按三件事（注册即回滚/补丁即差异/日志即事实源）跑。

## 二、核心架构（Cordis 式 monorepo，聚合不融合）

```
platform/（新 monorepo，Node+Cordis 与 radio/video 同栈）
├── apps/
│   └── portal/          ← 自 private-radio-stations/apps/portal 升级
│       库 Library：项目注册表驱动（启停/状态/健康/入口跳转）
│       工坊 Workshop：插件订阅/安装/更新/回滚/卸载 + 审计日志
│       引擎 Engine：alloy dump-profile / dump-log 网页化（CLI 调用）
├── packages/
│   ├── core/           平台内核：Context + registry + workshop + bus + WorldLog(JSONL) + invariants
│   └── schema/         项目清单 platform.yaml 规范 + 校验（fail-loud，对齐 HARNESS P1/P4）
├── registry/
│   ├── projects/       每个接入项目一个 platform.yaml（id/名称/端口/启动命令/健康检查/分类/发布面）
│   └── ports.yaml      端口分配表的机器可读版（单一事实源，表仍保留人类可读版）
└── workshop/           本地工坊状态（订阅清单 + 版本 + patch 记录 + 任务日志）
```

**三条铁律在架构中的落点**：
1. 每个插件独立更新：平台**绝不 import 项目代码**——项目仍是独立进程（crawl_hub 式子进程隔离），平台只做注册/启停/装配/审计；
2. 不盲目整合：接入是"登记 platform.yaml"，不是"迁入平台"；不接的项目照常独立运行；
3. 统一端口：新服务端口 = 查 ports.yaml 再开工；port 变更随插件版本留痕。

## 三、平台三个页面的语义（对齐 Steam）

| 页面 | Steam 对应 | 功能 | 数据源 |
|---|---|---|---|
| 库 Library | 游戏库 | 全部接入项目卡片：名称/分类/端口/运行状态/启停按钮/入口跳转（iframe 复用 portal 现状） | registry/projects/*.yaml + 进程探活 |
| 工坊 Workshop | 创意工坊 | 插件列表/订阅（clone+登记）/更新（patch）/回滚（注销+恢复）/卸载 + 每个动作一行任务日志 | workshop/ + gitee 发布面 |
| 引擎 Engine | （无对应，本仓特色） | alloy 装配视图：dump-profile 树、dump-log 审计、sync 状态 | alloy CLI |
